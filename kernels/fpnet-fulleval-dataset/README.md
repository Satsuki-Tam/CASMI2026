# casmi26-b1-fpnet-fulleval (private) — FPNet weights trained by us for the B1 pipeline

**What**: one FPNet checkpoint (`full_eval_final.pt`, spectrum → fingerprint logits, 49.7M parameters) trained on 2026-10-25 on our own machine
with the public training code, and the training records needed to reproduce it.

**Training code (public)**: `train_fivefold.py` of the dataset `dmitriigluzdov/casmi26-fold-safe-fpnet` (Dmitrii Gluzdov), run through a
Windows variant generated by `experiments/fpnet_full/make_win_trainer.py` in https://github.com/Satsuki-Tam/CASMI2026 (fork → spawn,
per-worker memory-mapped data, SIGHUP guard, recipe-aware input gate; the training recipe itself is unchanged). Model and data access:
`casmi` package of `ahmedberatozer/casmi26-v3-models` (Ahmed Berat Özer; FPNet architecture, `traindata.py`, `build.py`), fingerprint bits
`fp_bits.npy` (sha256 c3869e86…) unchanged.

**Data**: the competition `train.parquet` only (no NIST-derived data). Spectrum cache rebuilt with the public builder `casmi.build.build_spec_cache`
from a filtered copy of train.parquet (`experiments/fpnet_full/prep_full_eval.py`): removed = the 1,184 enveda-np-examples spectra and 12
same-molecule duplicates of them in other libraries; identity groups of our evaluation sets dev2 (500) and locked2 (500) held out; every
identity fold trained (no held-out fold). 2,524,870 training spectra, 82,855 updates (batch 256, lr 3e-4, cosine, seed 0), RTX 5070 Ti.

**Files**: `full_eval_final.pt` (sha256 in `SHA256SUMS`), `check_inputs.json` (input gate), `launch.json` (run arguments),
`full_eval_history.json` (training curve), `panel_dup_audit_summary.json` (audit of remaining near copies of the panel queries).

**Licence / terms**: weights derived from competition data — subject to the competition data terms (non-commercial use with attribution);
code licences as in the original sources (casmi package MIT; our scripts in the repository above).
