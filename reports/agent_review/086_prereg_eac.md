# 086 事前登録: EAc(比較可能な参照に限る EA)の開発の診断(Codex 072 / 084)

作成: 2026-10-27 17:36 JST(評価の前、Claude Code)。
- **変種(固定)**: eac0.5w1 = EA(θ = 0.5、w = 1)の罰則を、**同じ極性の参照を持つ候補**(refcmp_exact の n_cmp_pol_<view> > 0、厳密な再計算 = 表の参照数と 99.6〜100% 一致)に限る。EA と同じ候補・元 score・θ/w。θ/w の再探索はしない。
- 性質(Codex 084): EAc の罰則対象は EA の部分集合 → 参照の無い C2 の真について RR_base ≤ RR_EAc ≤ RR_EA。**成功の定義は「C1 の費用を減らしつつ C2 の利得をどれだけ残すか」**。
- 評価: v7f の主出力(gen_eval2pv、rank_v7a)で 053 dev f1/f2、f1dev、f2dev、パネル;0.379 の主出力(gen_eval2p、rank_v4b)で 053 dev f1/f2(比較用)。
- 読み(事前に固定): (i) C2 の保持 = 053 NP C2(H, N 等重み)で (EAc − main)/(EA − main) と EAc − EA を報告、許容損失は EAc − EA ≥ −0.003;(ii) C1 の費用 = 053 NP C1・パネル C1 clean・G C1 で EAc − EA を報告し、053 NP C1 で EAc − EA > 0 なら「費用を減らした」と読む。(iii) 真の参照が比較不能だった C1 の群を分けて報告。
- この 086 は開発の診断で、Public 候補の選択ではない(候補にするなら確認集合と C1 費用の測り方を別に登録する;083 は Codex 084 に従い B 経路の候補用に残す)。
