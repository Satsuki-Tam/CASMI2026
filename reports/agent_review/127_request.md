## 2. 利用者の決定(10/29 午後)
- 目標: **Public 0.500 以上**(金に必要という利用者の見立て)。自前の最高は 0.394。
- **MIST と ms-pred(GLACIER の timsTOF 微調整)の導入を許可**。MIST は Spark に導入済み: commit 48e339be の clone、別 venv(.venv の site-packages を .pth で参照、h5py のみ追加、MIST 本体は src を .pth、pip の build は走らせていない)、Zenodo の 4 ファイルを catalog の sha256 で検証しながら取得中。**aug の checkpoint は weights_only=True で読めた**(sha 一致、step 430,965、72,296,996 parameters、dataset msg_all)。
- 提出枠: **候補を優先**。診断の提出は必要なときに利用者へ相談する(fwdoff_B も相談の対象)。
- 公開ノートブックの扱い(利用者が繰り返し明言): 手法の参照・移植は許可。ただし E0 の弱点(Public 130 分子での選択・CV 無し・手元で検証できない・LB 合わせの定数)を踏まえて、**部品ごとに正しく改善できるかを考えて**移植する。E0 を提出の土台にはしない。賞の要件(第三者の重みの学習コード)は判断の障害として扱わない。

## 3. 移植の設計案(結果の前)
| E0 の要素 | 根拠 | 扱い |
|---|---|---|
| 誤り方の違う 2 本のリストの融合 | 今日の ENG_B / pre-rank2_B(隠しの B で +0.036)、文献(誤りの違う証拠だけが融合で報われる) | **移植する**。第 2 エンジンは本当に違う証拠で作る |
| 融合後の同分子式内の GLACIER 並べ替え | 自前の E2b(未見分子で z(FP) + z(GL) が単体より有意に良い)。隠しでの寄与は fwdoff_B で切り分け可能 | 移植候補(開発で検証) |
| 2 位挿入 | D = +0.010 | 移植しない |
| α 0.6・K 3・窓 40・blend 0.88・昇格閾値・PubChem の固定枠 | Public で選ばれた定数 | 持ち込まない。必要なら自前の開発 fold で決め直す |

| 大規模な模擬で ranker を学習(E0 約 2.4 万 query、v8w7a 3,931 群) | 069 の P1、v8w の小規模版が確認 +0.0067 | **127 の学習曲線**(診断、登録済み、評価中)で律速かを確認してから |
- 10/28 の E-lite(第 2 エンジン)が落ちた理由は、同じ FPNet・GL・library を使い回して誤りが相関した(正解順位の Spearman 0.62〜0.71)こと。E0 の engine 2 は別の FP モデル・MetFrag・ずらした library 類似度・別の学習行を使う。→ **MIST(MSG で学習した別系統、式条件付きの部分式割当 transformer)を第 2 エンジンの中心**にする。
- 117 の草稿(MIST を 111 と同じ 1 位固定の接続で足す)は、111 の結果(接続そのものの費用)を受けて組み直したい。案:
  - 段階 1(技術): A0 済み(aug)。A(公表値 0.433 / 閾値 0.1879 の再現、件数・集約法が一致する場合のみ)、B(batch・順序・CPU / GPU の不変)、C(新規 query の前処理が MSG の compact と離散値で一致)。
  - 段階 2(記述、判定に使わない): 開発表で MIST 単独の識別(中立の同点)、**v8w7a との正解順位の相関**(E-lite の 0.62〜0.71 より十分低いか)、救済 / 損失の構造。式は候補ごとの式で一回ずつ(同じ式の候補は予測を共有)か、P の 1 位の式か — どちらを主にするか。
  - 段階 3(候補、登録): 融合 C = RRF(または z 得点の凸結合)で v8w7a と MIST リスト(または MIST + MetFrag + shifted library の小さな第 2 ranker)を融合。定数は開発 fold で決め、主指標(1/4 NP_H C2 + 1/4 NP_N C2 + 1/2 D C2)、保護(G C1、NP C1、c1dev、旧 B)、未開封の確認(np096_conf093)→ Public 一回。
  - MSG への露出: 開発集合は not_msg で選んだ(MIST の学習分子と重ならない)。ranker の学習行に MIST 特徴を入れる場合は MSG に含まれる学習分子で記憶が入るので、露出の台帳で除外または印付け。
