## 質問
1. 評価の漏れ・偏り: C2 view のマスク(真の key・raw key・identity group)で十分か。**ライブラリ化合物は同じ研究・同じ寄託者の兄弟化合物を持ちやすい**(開発の C2 代理も確認集合も library 化合物)ので、どの library にも無い隠しのクラス 2 では近いアナログが少なく、利得が過大評価されている可能性がある。これを測る方法(例: 同じ寄託 library のアナログを除いた感度表、ingest_lib 別の利得)と、提出前に必要か。
2. 累積の dev2 D C2 −0.023(確認集合の D は +0.014)を提出の妨げとみるか。
3. 上の読みの規則の妥当性(期待値は class 2 の重み × +0.05 + class 1 の重み × +0.02 ≈ +0.01〜+0.02 で、Public の差の SE ≈ 0.016)。
4. DUP 診断(57645926)・T/COCONUT/band26 の結果(12:15 頃)との順序: 結果を見てから提出すべきか、独立なので先に出してよいか。
