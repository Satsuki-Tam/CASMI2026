## 動機
- F(P + E2 の RRF)の Public = 0.414(P から +0.020)。二つのエンジンの融合と E 源の優遇が隠しテストで効いた。
- いまのワークスペース v1 は P の上位 25 + 生成物だけで、E2 の情報を持たない。v1 で P を超えても、作業基準の F を超えたことにはならない(Codex 153 Q5)。
- v1 の到達の上限は 0.643(C1 0.806 / C2 0.833 / C3 0.225)。E2 の候補(E 窓の上位)を足せば、C1 / C2 の到達が上がる見込み(E 窓は COCONUT / PCL / BIO / train を ±10 ppm で全部含む)。
