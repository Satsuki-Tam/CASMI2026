# 048 事前登録(gt3t / ggt3t の結果の前に固定、00:32 JST): GL の無い分子の f·z gate を締める

- 背景: gt3(および ggt3 の fallback)は fold-2 locked の F/C1 で −0.0126(正解 3〜13 位の 10 分子が押し下げ)。GL の無い分子で f·z の gate(生成物の f·z ≥ 主出力 3 位の f·z)がゆるい(046)。
- 候補(アナログ親だけの生成物、b1_gen v2、挿入は 3 位のまま):
  - **gt3t**: 生成物の f·z ≥ thr で挿入、thr = max(有限な f·z(主出力 2 位), f·z(主出力 3 位))(現 gate との積集合 = 新たに通る候補は無い)。主出力の候補が 3 個未満なら gt3 と同じ(空き枠)。2・3 位とも非有限なら thr = −∞(gt3 と同じ)。
  - **ggt3t**: GL 経路(DB 側の尺度が成立し、生成物の上位 5 に有限の GL)は ggt3 と同じ gg3、それ以外は gt3t。
- 「GL 無し」の状態は ggt3 の定義どおり(尺度不成立・上位 5 が全て未採点 → fallback)。実行失敗・deadline 棄権は本番 pipeline で別に記録(評価器には無い)。
- 開発(どちらか一つを選ぶ): dev2 v2(full_eval)、fold-1 dev(fpnet_fold1)、**fold-2 dev**(fpnet_fold2、生成の評価に未使用)、パネル full_eval(保護)。C3 NP 等重み(各ブロック内 C/D/E/F 1/4、三ブロック各 1/3)。保護 = 全ブロックの C1(C/E/F/G)・C2(C/D/E/F/G)とパネル C1 clean / C2 で Δ ≥ −0.01。
  - **選択規則**: 保護に合格し、かつ C3 が対照(gt3t は gt3、ggt3t は ggt3)から 0.002 以上は落ちない候補のうち、C3 が大きい方。同点は gt3t。どちらも満たさなければ採用しない。
