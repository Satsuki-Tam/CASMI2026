2. **query の ID を不透明にする**(W135 の分子 ID は正解の InChIKey 系で、候補の key と照合すると正解に届く)。開発・test とも、ワークスペースに置く表は許可した列(allowlist)だけで書き出す専用の exporter を使う。query と identity の対応表・正解・クラスはワークスペースの外に置く。world 名・π・家族・used・擬似クラスはモデルの入力にせず、管理用のメタデータに分ける。
