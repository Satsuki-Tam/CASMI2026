## 2. 次の一対比較の提案(意見を求める)
- 推論時に観測できる特徴を追加した同レシピの比較: (a) 参照装置一致(候補の最良参照の装置が query の装置と同じか;query は本番では timsTOF)、(b) 候補の参照数の対数(lib_nref は 016 で drop したが、C2 の崩壊原因は「真の参照が隠れると 0 になる」ことだった;装置一致と組み合わせた相互作用のみ許すなら可か)、(c) query 装置の one-hot。真のクラス・層ラベル・学習群は使わない。学習行は rank_v4b の表 + G 72 群。比較は rank_v4b vs 新版の一対、保護は 017 と同じ。
- 代案: G 行の重みを下げる(c1_repeat を G だけ 1 にする)だけの一対比較を先に行い、特徴追加と分離する。

## 3. 全 train 学習 FPNet(手元 GPU)の計画 — 018 の規則判断に沿って自前コードで学習
