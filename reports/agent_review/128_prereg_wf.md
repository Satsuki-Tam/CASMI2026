# 128 事前登録(候補の探索 → 確認;結果の前、2026-10-29、Codex 127 Q2 の設計)— 同じ分子式の中だけの並べ替え(GL / MIST)

## 候補(2 系統、混ぜない)
- 対象: 凍結した主リスト P(v8w7a、gen_eval2fd --v7f --parents 0、既存の開発表と保存済み GLACIER)。各 (set, view, molecule) の view リスト全体で、候補を中性分子式 F(RDKit CalcMolFormula、代表 SMILES)ごとにまとめる。
- 並べ替え: **F の候補が P で占めていた位置だけ**へ、F 内を h = 1/(10 + r_P,F) + α/(10 + r_X,F) の降順(同点は P 順)で詰め直す。式をまたぐ位置は動かさない。P の 1 位も同じ式の中では入れ替わり得る。X が有限な候補が 2 未満の式群は P のまま、X 欠損の候補は F 内の最後(同点は P 順)。K = 10 固定、α ∈ {0, 0.5, 2}(α = 0 は「変えない」= P)。この後に global な融合はかけない。
  - **WF-GL**: X = 保存済みの GL(P が使っているのと同じ GLACIER の得点。新しい証拠ではなく、使い方の変更)。
  - **WF-MIST**: X = MIST(aug、step 430,965)の cos。実装 experiments/mist/mist_score.py:query は b1_features と同じ選択(最大 8)のうち [M+H]+ / [M+Na]+、候補ごとの式、質量整合 max(20 ppm, 5 mDa)の組だけ、(スペクトル, 式, 付加体)ごとに一回予測、候補 FP は Morgan 半径 2・4096 bit、cos を対応 query で平均。
- 実装(gen_eval2fd.py の `--wf` / `--wf_mist`、既定はオフで main は不変): 候補集合不変・式の位置不変・α = 0 で P を再現・P 自身の順位を X に渡すと P を再現、を各行で assert。上限 wf_ub(真をその式の最も早い位置へ上げた RR、25 位以内のみ)と、真の式内順位(P、X の悲観的な同点)を記録。

## 読み(結果の前に固定)
1. **上限での選別**(ラベルを使う): fold 1 の主指標の配置で wf_ub − main の全件平均が **+0.005 未満**なら、この位置保存の方策では関門に届かないので、その系統を止める(X の能力の否定ではない)。
2. **fold 1 での選択**(f1dev / np053f1dev / c1bankdev、111 と同じ関門): 系統ごとに α ∈ {0.5, 2} を評価。関門 = 主指標(1/4 NP_H C2 + 1/4 NP_N C2 + 1/2 D C2、全件の分母、対応の無い分子は差 0)≥ +0.005 かつ 95% 下限 > 0、block A(NP_H / NP_N C2)と block D の下限 ≥ −0.01、保護の下限 ≥ −0.01(旧 B = f1dev C/D/E/F C2 等重み、G C1 = f1dev、NP C1 = np053f1dev H/N 等重み、c1dev の C1 全件)。bootstrap 4000、seed は 111 と同じ割当。通過した中で主指標の最大の (系統, α) を **一つ**だけ選ぶ(同点は WF-GL、次に小さい α)。通過なし → 候補なし。
3. **fold 2 の安定性**(f2dev / np053f2dev、既使用なので独立確認とは呼ばない): 選んだ (系統, α) の主指標が正であることを記録。負なら確認へ進まない。
4. **確認(一候補、一回)**: 未開封の np096_conf093(NP_H 200 + NP_N 200、fold 0)と np102_d0conf(D 286、fold 0)を 1/2 ずつ(平均 ≥ +0.005 かつ下限 > 0、各ブロックの下限 ≥ −0.01)、C1 の費用は c1cost098(E 型 100、fold 0、下限 ≥ −0.01)。開封の前に台帳で未使用・重複・用途を確認し(得点は見ない)、表と GL・MIST の得点を作る。G 型の新しい C1 が無い限界は残す。確認を見て系統・α・候補を選び直さない。
5. **Public**(確認を通った場合のみ、利用者の許可のもと一回): v8w7a(0.394)比 ≥ +0.008 暫定採用の候補 / −0.015〜+0.008 保留 / ≤ −0.015 点検(これまでの読みの規則と同じ)。
