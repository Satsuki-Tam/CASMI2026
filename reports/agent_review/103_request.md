# 103 依頼: 102 の結果と文献調査を受けた今後 6 週間の本筋の選び方

## 1. 文献調査の要点(reports/CASMI 2026 順位融合と注釈伝播.md、4 本のメモ research_notes/CASMI 2026 順位融合と注釈伝播/)
- 融合が効くのは、誤りの重なりが小さい別系統のリストの組合せだけ。CASMI 2016 / 2017 の公開順位から再計算すると、同系統の道具どうしの正解順位(log)の相関は 0.45〜0.83、別系統は 0.03〜0.3。指紋型 + 別系統の組は、指紋型 2 本の組より oracle MRR が高い(0.536〜0.548 vs 0.499)。等重みの 6 道具の融合は oracle の余地の約 24〜30% しか回収しない。保留集合では Top-1 が僅かに下がり Top-10 だけ上がる例もある。弱いリストとの等重み融合は Top-1 を下げる(ESP、LambdaMerge)。ラベル付きの検証があれば、凸結合の重み調整が RRF に勝つ(Bruch 2023、9 データ全て)。
- 強い prior(参照数)は断片化の道具を圧倒する(CASMI 2016: 参照数だけで Top-1 143 vs 6 道具の融合 82 / 208)。一方、**天然物中心の CASMI 2017 では人気度の付加が逆効果**(CFM-ID の Top-5 59% → 53%)— 090 の「隠しの正解は開発より人気度が低い」と同じ向き。
- ネットワーク伝播: アンカー無しの NAP Consensus で正解順位の中央値 5 → 2(類縁を持つスペクトルに限る)。分子式の一括推定(ZODIAC)の効果は大きい。同一装置のバッチでは偽の辺が多い(自前の監査でもパネルの最近傍 sim ≥ 0.6 の 79% が非類縁)。
- 類縁構造の生成: 到達しても選べない(FOAM: 到達 68%、Top-1 11%;候補を増やすと Top-1 が悪化;**著者の結論は「スペクトル予測の精度が律速」**)。位置異性体は前方モデルでは区別できない(ModiFinder)。

## 2. 102(E-lite)の結果(reports/agent_review/102_result.md、diag/x102_summary.md)
- **選択なし**。主指標 1/2 A + 1/2 B_D: p_e −0.011、e1b −0.006、e1r +0.002(いずれも区間に 0)。A(053 NP C2)は全候補で + (+0.017〜+0.039)、B_D / 旧 B は − 、正解が E 源の外の C2 行は −0.12(害)、G C1 は +0.043〜+0.048、パネル C1 clean は p_e +0.004 / e1b −0.018 / e1r −0.035。
- 機構: 効果の大半は**候補源の再加重**(E 源の正解は救い、PubChem のみの正解を壊す)。正味は隠しの正解の候補源の構成で決まる。
- 探索: 同じ α で rrf_e − rrf_p_e = e1r **+0.0133 [+0.0060, +0.0211]**(A +0.023、B_D +0.004)= 人気度を使わない別順位そのものの価値。費用はパネル C1(E 単体 0.69〜0.79 vs main 0.925)。
- **証拠の系統の監査**(diag/fam_audit.md、記述): E-lite と main の正解順位(log)の Spearman は 0.62〜0.71(文献の「同系統」の範囲)、pair-oracle の余地は A +0.05、旧 B +0.04、G C1 +0.06、パネル C1 +0.01。単一証拠の MRR(A): FP 0.185、GL 0.258、人気度 0.337、library 0.110、main 0.588。**人気度単独の MRR は層で極端に違う: パネル C2 0.805、A 0.337、旧 B 0.139、B_D 0.070、G C1 0.010(Public の人気度だけの順位は 0.135 ≈ 旧 B)**。パネル C1 を保護に使うと、人気度を使わない変更は構造的に罰せられる(パネルの人気度は隠しとかけ離れている)。
- G C1 では E 窓に絞るだけ(p_e 単体 0.927 vs main 0.883)で改善 = 主リストが train 構造の正解の上に PubChem のみの decoy を置く誤りが約 5%。
