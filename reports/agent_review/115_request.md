## 根拠
- **P の誤りの構造監査**(diag/x_fpcoll.md、既存の top-25 と表のみ): fold 1/2 の C2 で正解が候補内にあるのに 1 位を外した 560 件。誤った 1 位の 92% は同じ分子式だが、**10,226 bit の FP が正解と完全一致する候補は 0 件**、誤った 1 位と正解の Tanimoto は中央値 0.63。→ FP 表現には区別する情報があり、律速は**スペクトルからの FP 予測の精度**。
- 公開の fold-safe FPNet の検証(FIVEFOLD_VALIDATION): 一般の held-out 構造の top-1 68% に対し NP 例は 33%。NP 構造への汎化が弱い。隠しテストは NP(B 群 = COCONUT にあり train に無い構造が Public の得点の大きな部分)。
- 文献(reports/research/contrastive_msms_retrieval_2026-10-28.md の [9]): 学習分割だけで学習した ICEBERG で PubChem 構造の模擬スペクトルを作り MIST を学習すると、MassSpecGym の同式候補で R@1 9.57 → 53.76%(著者が漏洩なしとした設定)。ただし同じ表で PubChem の既定順だけで 49.98% に達し、候補集合の偏りの寄与が大きい。ホストは GLACIER / ICEBERG(MSG 重み)と MIST の 'aug'(MSG + GLACIER 模擬スペクトル)を名指しで許可。

## 案(パイロット)
- GLACIER で COCONUT 構造の [M+H]+ / [M+Na]+ の模擬スペクトル(CE は "sum" か数段)を作る(約 270 予測/秒 → 40 万構造 × 2 付加体で 1 時間弱)。予測ピークを保存する runner の版(gl_runner の予測部分は不変、出力だけ追加)を作る。
- fold-1 の公開 FPNet を初期値に、**実スペクトル + 模擬スペクトル**の混合 batch(例: 25% を模擬)で固定更新数だけ微調整。**対照 = 実スペクトルだけで同じ更新数の微調整**(追加学習そのものの効果を分ける)。評価は 110 と同じ段階 1(FP 単独、同じ窓)→ 段階 3(端から端)と保護。
- 模擬の対象から fold 1 と NP 例の identity group の構造を除くか(厳しい版)、本番と同じく COCONUT 全体を使うか(本番では隠しの正解が COCONUT 構造なら模擬集合に含まれ得る;ラベルは使っていない)。開発の正解は MSG に含まれない(053 / p2_select は MSG を除外)ので、GLACIER が開発の正解の実スペクトルを記憶している経路は小さい。
