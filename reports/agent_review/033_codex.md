**Q1：コミュニティの twin 得点は研究の手掛かりになるが、今の B1 twin の観測値としては扱えません。**

最初に得点の来歴を確認する必要があります。[topic 742088](https://www.kaggle.com/competitions/enveda-CASMI26-molecule-id-mass-spectra/discussion/742088)の09/19の保存本文は 0.275 を110/400行と解釈し、visible test と Public の説明も混在しています。chain Notebook が述べるのは、10/07のmetric・再実行データ変更を反映した**各versionの表示得点**を使うということです。過去の掲示板本文の数値まで更新されたことを保証しません。当該probeの提出/Notebook versionと現在の得点が照合できなければ、0.275は現在の同じ採点対象での確定観測にはしません。今回Webから本文を取得できなかったため、この確認は保存資料の範囲です。

得点が同じ基準だと確認できても、外部の単一予測と B1 の単一予測は別の関数です。質量窓、query/参照の前処理、類似関数、adduct/CE集約、候補資格、公式identity、DUP、参照cap、tie-breakを揃える必要があります。「最良参照」という名前の一致では足りません。共通の query・参照条件で外部実装と B1 の top-1 key の一致を測り、定義差の影響を先に確認してください。

同じ分子集合で二つの単一予測が異なる割合を ε とすれば、両者の正解率の差は最大 ε です。ただし局所の ε が隠しでも成立する保証は別です。一律に「何%まで同じ観測でよい」という境界はなく、比較したい +0.015 程度の利得や較正許容幅に対して、定義差が判断を変え得るなら同一観測にはできません。未解決なら `external_twin = B1_twin + 転用誤差` の感度分析にし、誤差0で重みを狭くするモデルBを主判断にしないことを勧めます。別系列の再実行変動を、この単一probeの誤差「±0.016」としてそのまま使う根拠もありません。

現行得点と train 内の正解構造への一致が確認できた場合、0.275はその外部規則が正解した比率であり、Class 1比率の下限として参考になります。しかし、B1が解く分子との重なりは不明です。事前登録§2は次のように修正してください。

- `P_T < 0.275`：同じ採点集合なら、B1のtrain内順位の平均RRが外部の単一予測の正解率を下回る。外部twin正解分子をB1が候補外に落としたとは限らず、全て候補内でも2位以下なら起こる。
- `P_T ≥ 0.29`：B1の総RRが高いだけで、外部twinが正解した分子を回収済みとは言えない。別の分子で稼いでいる場合がある。「残りの差は非trainかzero」とは結論しない。

公開chainで同じ変更が複数枝に効いたことは優先順位の参考になりますが、共有モデル・系譜・Public集合を使うため、独立した再現実験の本数とは数えません。

**Q4：T probeはパネル型とG型をほとんど分けず、負のtwin結果もG比率だけを否定しません。**

必要なのは「同じ分子で B1が誤り、twinが正しい」頻度と、その逆の頻度・RR損失です。Tの総得点や外部twinの総得点だけではこの同時分布は得られません。さらに今回のhard C1型はC/E/F/Gを固定した局所比率で混ぜており、隠しでその内訳が同じ保証もありません。モデルBのhard型への重みを、隠しのG型比率と呼ばないでください。

局所では、identity既見・query取得未見を確認できるC1について、twinがB1の何位にいるか、B1との不一致、sim/margin、同装置・adduct・CEの参照被覆別に、救済/損失を同じ分子で測るのが有用です。dev2 GのFP未見の大きな利得と、パネルcleanの既見の利得を別に置き、031の対称maskは副表にします。取得情報のないGを、隠しの既見・独立取得C1の直接測定へ読み替えないでください。

一度のtwin比較が負だった場合に言えるのは、固定した変種のPublicでの総損益が負だったことです。C2損失の過小評価、露出、mask、外部twinとの差、融合の順位などでも説明できるため、「G型比率が誤りとして閉じる」は狭すぎます。追加の条件別Public probeを連発せず、仮説のどの積が外れたかを局所の同時誤差表で調べるのがよいです。

**Q5：DUPとの相互作用は大きくなり得るので、比較の土台を固定する。**

| 構成 | entropy除外 | twin先頭化 |
|---|---|---|
| A：作業用基準0.370 | 0.98 | なし |
| B：提出済み57645926 | 無効（1.01） | なし |
| C：今回のtwin単独候補 | 0.98 | 固定した一規則 |
| D：将来の組合せ候補 | 無効（1.01） | 同じ一規則 |

局所で比較できる条件では、相互作用は `(D−B)−(C−A)` で見ます。DUP解除はtwinそのもの、sim/margin、候補、GL被覆を変え得るので、BとCの利得を足してDを予測しないでください。DUPが正でも、真のtwinが復活したとは限らず、誤候補が強くなった場合も含みます。逆に、元から正しかった分子でtwinが強まるだけなら先頭化の追加利益は小さくなります。

今回の一変更を測るなら C−A です。DUPの結果を見て黙って D−A に変えると二変更になり、033の登録した比較ではなくなります。Dを次の作業用基準候補にする場合は、組合せとして改めて登録・保護確認してください。
