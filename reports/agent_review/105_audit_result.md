## 読み
1. **クラス 2(COCONUT 正解・f1/f2)の誤りの相手は「強い decoy」**: 誤りの 9 割は同じ分子式の decoy で、どの単独証拠も正解側を支持するのは誤りの 1/4〜1/3 だけ(FP は損傷率 0.36〜0.42 と救済率と同程度 = 境界では五分五分)。既存の証拠の組み合わせを変えても救える余地は小さく、**証拠の質(異性体の区別)を上げる必要がある** → 前方モデルの適応(105)や、より強い / 別の FP を優先する根拠。
2. **G C1(timsTOF のクラス 1、FP が同一性を未学習)では library が誤りの 66% を救い、損傷 5%** — 主リストが timsTOF query の library 一致を過小評価。ただし FP が同一性を学習済みのパネル(隠しのクラス 1 に近い条件)では救済 0.67 と損傷 0.09 が相殺(033 の twin 分析と同じ)。
3. 人気度は A では救済 0.32 / 損傷 0.17 と効率が良いが、旧 B では 0.26 / 0.35、G では損傷 0.54 — 人気度の効き方は層で逆転する(090・102 と整合)。
