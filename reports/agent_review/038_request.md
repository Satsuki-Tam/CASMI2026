# 038 依頼: MetFrag-lite(自前)を v7a 組合せの GL 不足分子に足す版(v7f)を、037b の候補と差し替えてよいか(anaw0.5 の結果の前)

## 結果(`038_prereg_frag.md`、事前登録 → 結果)
- `b1_frag.py`(自前): 1 本の非環結合 / 2 本の非環結合 / 同じ環の 2 結合で切った断片、重原子 + 付いている H、イオン = 質量 + h·H ± proton(h −2..+3)、前駆体 − 0.5 Da より下の上位 40 ピーク、説明された強度の割合(1 本 1.0、2 本 0.6)、query スペクトルの最大。設定はフォーラムの held-out ablation(topic 743254)に事前に固定。
- 開発(036 の 11 層、v7a 組合せ比): **v7ffb_1(GL 不足の経路だけ +1·z(frag))+0.0073**(最小層 −0.0004、パネル C1 clean・C/G C1 は不変)→ 事前規則を通過。両経路に足す版は G C1 で −0.006〜−0.016。FE だけに足すと +0.009〜+0.012(アナログの +0.041 より小さい)。
- 確認(conf3 + fit pool + fit pool 2、fold-0、再利用の集合): v7ffb_1 − v7a 組合せ = **C2 全体 +0.014 [+0.006, +0.023]**(E C2 +0.031 [+0.014, +0.049]、F +0.007、G +0.002、C/D 0)、C1 全体 +0.003 [−0.003, +0.009](F C1 −0.022 [−0.064, 0.000])。
- 実装: pipeline `--frag_w_fallback 1`(GL 不足の分子だけ遅延計算)、parity16 両 view PASS(16/16 一致、fallback 4 分子で frag 適用)。凍結 `experiments/b1_v7f038`(pipeline 6e3b4d04、b1_frag 8d552002、他は v7a と同じ)、kernel `casmi26-b1-fpnet-v7f`(lzma、1,040,594 bytes)smoke 中。

## 提案
- 037b の候補(v7a 組合せ)を **v7f(v7a 組合せ + GL 不足の分子に MetFrag-lite 重み 1)** に差し替える。分岐 A/B と読みの表は 037b のまま(比較対象は分岐で決まる)。frag の部分は小さい(確認の C2 +0.014)ので、一回の比較で v7a と frag を束ねる(Codex 028 の小さな変更の束ね)。
- 代案: 037b のとおり v7a を先に出し、v7f はその後の別比較にする。
