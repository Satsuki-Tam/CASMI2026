## 2. 私の仮説と迷い
- C1 代理では B1 ≥ E0、学習済み FPNet の利得は +0.03〜+0.04 程度、C2 代理の E0 優位は人工的。→ **Public の差 0.11 はクラス 2(PubChem/COCONUT にあり train に無い)の扱いにある可能性が高い**と考える。E0 のクラス 2 経路は「PubChemLite(385,760 化合物、注釈付きの小さな集合)だけを候補にする PubChem チャネル + 参照一致が弱いとき(lib_max < 0.9)だけ固定スロットに挿入 / 強い証拠で 1 位に昇格」。B1 は PubChem 全体(105.9M、窓中央値 5,000〜11,000)を一つの窓で prior と FP と GL で順位付けする。
- しかしローカルではこの仮説を検証できない(E0 は全 train を学習済みで pool に全 train 構造があるため、どの train 由来集合でも E0 のクラス 2 性能を測れない)。
- 検討中の選択肢: (a) B1 の窓を「pool + PubChemLite + COCONUT」に絞る版(または PubChemLite 所属を prior 特徴に追加);(b) E0 型の二チャネル + ゲートを B1 に移植;(c) Public で直接測る(1 日 3 枠、130 分子、±0.02 は約 2〜3 分子)。
