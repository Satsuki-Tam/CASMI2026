# 111 事前登録: 自前のスペクトル–分子採点器 N を 1 位固定で接続(Codex 111 の設計)

作成: 2026-10-28 21:09 JST(Claude Code、学習前・結果の前)。Codex 111(REVIEW_COMPLETE: 111)の推奨をそのまま固定する。110 の評価を先に行い、111 の学習は 110 の学習終了後に GPU で行う。

## 1. 候補(一つ)と対照
- **C_N** = 凍結した主リスト P(v8w7a、gen_eval2fd --v7f --parents 0、既存の fold-1 表 run_f1dev / run_np053_f1dev と保存済み GLACIER)の **1 位を固定**し、その view の**全 shortlist**(公式 key で重複除去済み)の残り全候補を `s = 1/(10 + r_P) + 0.5/(10 + r_N)` の降順(同点は P の順)に並べ、最後に 25 件で切る。r_P・r_N は全 shortlist での 1 始まりの順位(N の欠測は最下位)。先頭を除いた後に r_N を付け直さない。
- 対照: **C_Fs** = 同じ接続で N の代わりに Fs(基準 FPNet の 1 スペクトルずつの logit 平均と候補 FP の内積)= 入力形式の効果。P = 不変。採用候補は C_N だけ。C_Fs を後から候補へ繰り上げない。
- 評価器の実装(gen_eval2fd.py `--nscore`)は main の計算を変えず、候補集合の保存・先頭 key 不変・RR = 1 の行の不変を assert する。

## 2. モデルと学習(結果の前に固定)
- 初期値: 公開 fpnet_fold1(seed 0、fold 1 + NP 例 group を保留、sha256 1739d568…)を weights_only で読む。新しい頭: スペクトル射影(1024 → 1024 → 256)、分子 MLP(FP 10,226 bit → 1024 → 256、dropout 0.1)、学習する温度(初期 1/0.07、[1, 100] で clamp)、両側を L2 正規化。**推論の N = 照会スペクトルごとの cos(s, m) の平均**(= m と単位埋め込みの平均の内積;生の埋め込みを平均して再正規化しない)、FP 項なし(w_fp = 0)。
- 更新: FPNet の全層(lr 1e-4)と新しい頭(lr 5e-4)、AdamW(wd 0.01、bias / norm / 温度は減衰なし)、warmup 500、各 run の総更新数で 2% まで cosine、batch 256、merge_p 0.3 と公開の augmentation、seed 0、bf16。
- 損失 = CE_cos(正例 1 + 負例 63)+ 1.0 × 公開の f·z 順位 CE + 1.0 × FP BCE + 0.1 × 元素(後三つは補助)。
- 正例: split のラベル train の学習スペクトルだけ(f1s1 と同じ split ファイル;n111/r1 で split 監査 14/14 PASS)。
- 負例(Codex 111 (2)(3)): pool の ±10 ppm 窓から、**保留 identity group(fold 1 + NP 例)の構造をすべて除いた**集合(710,701 中 55,035 を除外)と、**正例自身の identity group を除いた**有効候補だけを使う。**同分子式への集中(固定比率)**: 有効な同分子式の候補が 8 件以上ある窓では 63 のうち 48 をそれらから、残り 15 を有効な窓全体から(いずれも一様・復元抽出);8 件未満なら 63 を有効な窓全体から;有効候補 < 8 の窓は半分を有効な無作為 decoy、0 の窓は全部。集中の適用率・同分子式の負例率・小さい / 空の窓の率を記録。評価の誤答から負例を採らない。(初版は窓の一様抽出で同分子式 49% だった;Codex 111 が 111 の差分に挙げた「同分子式に集中した負例」に合わせ、結果の前に変更)
- 学習中の評価なし。保存は固定の更新数だけ。
- **学習量(Codex 111 Q3、速度試験の後・性能の前に確定)**: 三つの別 run(それぞれの更新数で LR を終える): **2,000 / 8,000 / 20,000 更新**。seed・batch・負例・損失は共通。途中 checkpoint は使わない。

## 3. 評価(fold 1、結果の前に固定;読み取り = x111_summary.py)
- 採点: n111_score.py が既存の表の全候補行に N と Fs を付ける(query は b1_features と同じ選択・最大 8・電子補正、1 スペクトル = 1 入力)。欠測は NaN のまま数える。
- 検査(STOP): 完全性、値が [0, 1]、**main が diag/r102 の main と全行一致**、N / Fs の欠測 0、RR = 1 の行の不変、cell 内で identity group 一意。
- 主指標 = 1/4 d(np053f1dev NP_H C2) + 1/4 d(np053f1dev NP_N C2) + 1/2 d(f1dev D C2)、d = C_N − P。関門: 主指標 ≥ +0.005 かつ 95% 下限 > 0;A(NP_H / NP_N C2 等重み)・D の各ブロックの下限 ≥ −0.01;保護の下限 ≥ −0.01: 旧 B(f1dev C/D/E/F C2 等重み)、G C1(f1dev)、NP C1(np053f1dev NP_H / NP_N 等重み)。NP_X は記述。bootstrap 4,000 回(cell 内で identity を再標本化)、seed 固定。空の cell・未判定の保護は不合格。
- **学習量の選択**: 関門を通る checkpoint のうち主指標が最大のもの(同値は短い方)、どれも通らなければ候補なし。選んだ区間は選択込みの独立確認ではない。
- 併記(判定に使わない): C_N − C_Fs(主指標の重み;下限 > 0 なら入力形式を超える追加価値を支持、そうでなければ原因は未確定)、C_Fs − P、N 単独・Fs 単独の MRR、救済 / 損失の件数、主リストと N の正解順位の順位相関、1 位固定の上限(正解の元順位 > 1 なら 0.5 − RR_P)。
- **事前に計算した上限**(既存 r102、結果の前): fold 1 主指標の上限 = **+0.0568**(NP_H C2 +0.076、NP_N C2 +0.102、D C2 +0.025)、fold 2 = +0.0582。関門 +0.005 には到達余地がある。
- 機構の診断(x111_diag.py、ラベルを使う記述、判定に使わない): 真と同じ分子式の候補がある群の群内 MRR(N / Fs / 表の fp)と群の大きさ、FP の衝突(真と bit 列が同一の同分子式候補)の率、**学習で見た構造への偏り**(N / Fs / fp の 1 位が train 構造である割合、train 候補の平均順位の百分位)、真の順位の中央値(N vs Fs)。
