## 2. NP の正解では GLACIER が弱く、prior が強い(C2、GL 被覆あり、未見)
- C 層: COCONUT の正解は GL の順位の中央値 **20**(top-1 5.8%)、tier のみの正解は **2**(top-1 41%)。D 層: 8 vs 4。GL は「正解と同じ型(NP / 合成)」の候補を上げるが、NP の異性体の間ではほぼ識別できない(正解が COCONUT のとき COCONUT デコイの GL z は tier デコイより +0.6 高い)。
- 固定規則 S = z(FP) + wg z(GL) + wp pop の格子: COCONUT の正解は wg 0〜0.5 が最良(C: 0.596 vs 登録の wg 2 で 0.450)、tier のみは wg 1〜2 が最良。
- learned を含む blend(analog 項なし)では差は縮む: COCONUT の正解は 2 z(L) + z(S) の S の wg を 2 → 0.5 にすると C 0.615 → 0.633、D 0.535 → 0.561、tier のみは C 0.681 → 0.642、D 0.590 → 0.585。
- PubChemLite 加点は dev では小さい(D の COCONUT 正解 n 23 で w 4 のとき +0.06、他はほぼ 0)、パネルは天井近く(0.961 → 0.974)。

## 3. 含意(仮説)
- 開発の判定と融合の重みは、正解の 2/3 が非 NP(GL が強く prior が弱い)の集合で決めてきた。隠しの NP(パネル型)では GL の価値が低く、prior の価値が高い可能性が高い。E0 系譜は LB で直接調整しているので、この差が 0.085 の一部を説明し得る。
- 次の評価は「正解が NP(COCONUT / LOTUS)」の分子に限定・再重み付けすべき。train ∩ COCONUT は約 2.6 万 identity あり、MSG を除いても fold-safe な NP クラス 2 の開発・確認・ranker の学習に十分な数がある。
- 今日の prior-only probe(枠 2)は、隠しの正解がどれだけ「よく知られた化合物」かを直接測る(パネル型なら高い値が出るはず)。

## 4. NP の正解が 1 位を逃すとき、勝つのは何か(`np_top1_source.py`、blend = 2 z(L) + z(S)、analog 項なし)
| 正解 | GL | n | 正解が 1 位 | 1 位を逃した時、勝者が COCONUT 構造 | 勝者の pop 中央値 / 正解の pop 中央値 |
|---|---|---:|---:|---:|---|
| COCONUT(NP) | あり | 75 | 0.467 | 0.80 | 10.0 / 7.4 |
| COCONUT(NP) | 無し | 168 | 0.268 | 0.91 | 12.5 / 7.0 |
| 非 NP | あり | 167 | 0.503 | 0.10 | 2.6 / 2.1 |
| 非 NP | 無し | 137 | 0.146 | 0.46 | 7.7 / 2.2 |
- NP の正解は「PubChem だけのデコイ」ではなく「**より有名な別の NP 異性体**」に負けている(リスト中の COCONUT 構造は中央値 14% しかないのに、勝者の 80〜91% が COCONUT)。→ pool だけの窓(E0 engine-1 型)にしても、この負け方は減らない。スペクトルの証拠(FP・GL)が NP 異性体の間で弱く、prior(有名さ)が勝負を決めている。
- 改善の方向: NP 異性体の間の識別(FPNet の ensemble・ICE と GL の併用・MIST)、または「どの異性体か」の prior(分類学・NP クラスの整合など)。隠しの正解がパネル型(有名)なら現行の prior で勝てる側、有名でない異性体なら証拠の改善が要る — 今日の prior-only probe がこの比率を直接測る。

## 5. prior の強さ(窓全体の順位、b1_features の truth_*_rank、ラベルは評価側だけ)
| 群 | n | FP 単独 top-1 / MRR | FP + 0.15 prior | FP + 0.5 prior | prior 単独 top-1 |
|---|---:|---|---|---|---:|
| パネル未見(Enveda NP、timsTOF、fold-safe FPNet) | 205 | 0.117 / 0.240 | 0.693 / 0.807 | **0.756 / 0.854** | **0.707** |
| dev の COCONUT 正解 | 247 | 0.126 / 0.228 | 0.296 / 0.429 | 0.316 / 0.457 | 0.219 |
| dev の非 NP 正解 | 461 | 0.234 / 0.339 | 0.245 / 0.352 | 0.115 / 0.188 | 0.054 |
- FP 単独の力は群で大差ない(MRR 0.23〜0.34)。差は prior: パネル型の有名な NP は **prior だけで 7 割が 1 位**(窓 ~6,000 構造)。
- 含意: 隠しの class 2 がパネル型なら FP + prior だけで MRR 0.85 に届く。B1 の 0.379(E0 0.464)からは、隠しの多くはパネルほど有名ではない、またはクラス 3 が大きい、のどちらか(両立も)。PU(054)で B1 の主出力がパネル型の NP をどこまで取れているか(GL・ranker が prior の邪魔をしていないか)を測る。
