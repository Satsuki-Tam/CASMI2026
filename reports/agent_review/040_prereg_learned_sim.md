# 040 pre-registration: learned spectral similarity for the analog channel (own MS2DeepScore-type model) — written 13:23 JST, before any code ran

Motivation: the analog channel (034/035) is the first lever that moved class 2 consistently; its retrieval uses the entropy similarity (+ precursor shift). Literature: MS2DeepScore (Huber et al. 2021, J Cheminform) predicts structural (Tanimoto) similarity from a spectrum pair and beats cosine / modified cosine for finding analogs; MS2Query (de Jonge et al. 2023, Nat Commun) builds reliable analog search on it. Our queries are timsTOF while most references are other instruments — the regime where a spectrum-shape similarity is weakest.

Model (own code, trained only on train.parquet): binned spectrum (0.1 Da, m/z 10-1000, sqrt intensity, L2) + polarity → MLP siamese encoder (→ 256-d), cosine of the two embeddings regressed on the Morgan (r2, 2048) Tanimoto of the two structures; pairs balanced over 10 Tanimoto bins (MS2DeepScore recipe). **Every identity group appearing in any evaluation / confirmation / ranker-fit file is excluded from training** (dev2, locked2, conf3, fit pools, panel, W7 / p1 run1, eval_c1, locked seed 4, E2 sets), so evaluation molecules are unseen by the similarity model.

Use (variants fixed now): analog retrieval and weighting by the learned similarity instead of entropy (ls), and the combination (max of the two weights, lsmax); candidate features exactly as before (ap = max tan × w³); blended as in the registered candidates (anaw0.5-type on FE, and inside the v7f routing). Selection: the 036 11-layer rule; a learned-similarity variant replaces the entropy one only if ≥ +0.005 on the objective with C1 (panel clean, C, G) not more than 0.005 below; then confirmation on the confirmation sets and Codex review. A first sanity check before any variant comparison: on held-out validation pairs, the learned similarity must correlate with Tanimoto better than the entropy similarity (otherwise stop).

## Sanity check (13:39 JST): PASS
- ls_v1 (60,000 steps, 1,228,065 training spectra of 262,185 keys; 5,743 evaluation identity groups excluded): on 2,989 held-out-anchor validation pairs, Pearson with the structures' Tanimoto **0.673 (learned) vs 0.548 (entropy + shift)**, Spearman 0.659 vs 0.557 (best validation Pearson 0.689 on 20,000 pairs). → proceed to the analog-feature comparison.

## Result (14:05 JST): NOT adopted
- On FE (11 class-2 layers): anaw0.5 (entropy) +0.0408; learned lsw0.5 +0.0164 (min −0.034), lsw1 +0.0076 (min −0.067), max-of-both lsmw0.5 +0.0199, lsmw1 +0.0114. Confirmation sets vs anaw0.5: lsw0.5 C2 −0.020 [−0.031, −0.009], C1 −0.024; lsw1 C2 −0.020, C1 +0.023 [−0.000, +0.046].
- Pattern: the learned similarity finds the same compound across instruments better (dev2 G C1 +0.21 for lsw1 vs +0.18) but hurts class 2 (C −0.03/−0.05, G −0.02/−0.03, panel C2 −0.067): in the C2 view it gives high weights to library decoys whose spectra resemble the query (their self-match then lifts them), while the entropy similarity reserves high weights for genuinely matching spectra.
- Reading: a better pair-level Tanimoto estimate (Pearson 0.673 vs 0.548) did not translate into a better ranking channel; the analog channel's value comes from high-precision matches. Recorded and dropped for the analog channel (model kept at experiments/b1_baseline/ls_v1 for possible class-1 uses only after a separate registration).
