## 4. 源の事前分布(本質的な不確実性)
- W135 の母集団は「fold 1 の COCONUT にある正解」(census: 47,917 identity のうち 1,937)。世界の C1 / C2 の正解は全員 COCONUT にある。dev の表で、π0.3 C2 の正解の in_coconut 1.000(他の候補 0.275)、in_Ewin 1.000(0.415)。C1 の正解は in_train_w 0.996(0.059)。
- FH-PEB はこれを強く学ぶ。**反実仮想(x161_stress.py)**: 学習済みの fold のモデル(OOF を全 fold で完全に再現)で、C2 の正解の行だけを「E の源の外」(E の特徴を欠けの状態、源の旗 0、F の順位を同じ規則で作り直す)にすると、主 π0.3 の C2 の対象 429 件で、実際 F 0.7131 / FH 0.8814(+0.168)に対し、**反実仮想 F 0.3036 / FH 0.1217(−0.182)**。
- C2 の正解のうち E の源の外の割合を q とすると、F に対する差の期待値は q = 0 +0.168、0.1 +0.133、0.2 +0.098、0.3 +0.063、0.5 −0.007(**損益分岐 q ≈ 0.48**)。π0 でも同じ。
- 外部の手がかり: Enveda の天然物 panel(timsTOF、250)は 249 / 250 が COCONUT(001 / 023b)。F(E の源の候補を優遇する RRF)は世界 +0.018、Public +0.020 で移った。どちらも q が小さいことと整合するが、隠れた test の q は直接は測れない。

## 5. 読み
- FH-PEB の利得の中心は、C2 の正解が F の上位 25 にある query での並べ替えで、その大部分は「E の源(COCONUT など)の候補を強く優先する」学習による。世界では作為的に完全な信号なので、世界の +0.08 はそのまま Public に移らない。移る量は q に依存し、q < 0.48 なら正、panel の値(0.4%)なら大きい。
- C3 の +0.059 は家族のバッチの peer に依存する生成で、隠れた C3 では小さい可能性(公開の議論 753400)。
- 次の判断(Codex 161 に依頼): 固定の FH-PE との比較、holdout e に持ち込む凍結の候補、Kaggle の notebook への移植の範囲(PE だけか、生成物 B も含めるか)、源の頑健化(学習で E の特徴を一部欠けにする等)を入れるか、被覆の調査の優先度。
