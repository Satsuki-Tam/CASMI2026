# 001 判断記録(Claude Code、2026-10-24 02:40 JST)

対象: `001_request.md` と `001_codex.md`。

## 採用する点

1. **E0 は基準提出として実行する。** smoke コミット完了後に `kaggle competitions submit -k hayatetaf/casmi26-baseline-v18 -v 1` で本番再実行に出し、実測スコアと stage ごとの時間・有限スコア率・fallback 件数をログから取る。12 分子 smoke の成功を 400 分子の性能や所要時間の証拠とは扱わない。
2. **H1 は「既存機能の再実装」ではなく「失われている証拠の回復」に絞る。** V18 にはすでに TOPN=60 の ICE 候補生成、[M+NH4]+/[M-H2O+H]+ の GL proxy(N1)、ICE+GL 併用、window 40/80 を受け付ける融合関数がある。確認対象は、セル 44 `rerank_row` の `if ice and gl:` で ICE 辞書が空のとき有効な GL スコアが `unrescored` に落ちる分岐。E0 出力の `experiment_audit_factorial.csv` で `branch == unrescored かつ gl_finite_count > 0` の件数を数え、0 件なら候補から外す。あわせて ICE の subprocess が総失敗({})した場合に全分子の GL 再ランキングが無効になる経路も確認する。
3. **全アダクトへの一括拡張はしない。** MassSpecGym 版チェックポイントが対応するのは正モード [M+H]+/[M+Na]+ と QTOF/Orbitrap トークンであり、負モードや K+ への拡張は質量変換が可能でも断片化予測の根拠がない。
4. **H2 のルール一括削除はしない。** 旧パネルでも PubChem 挿入を外すと pool 除外シナリオの MRR が 0.519→0.361 に落ちる事実があり、「削除=頑健化」は成立しない。ルールごとに作用分子数と改善/悪化を分けて測る。
5. **E3 の採否基準を拡張する。** パネルのブートストラップ区間だけでなく、凍結比較での効果量、作用分子数、悪化例、学習への混入、別分子集合での方向、実行時間を判断材料にする。独立評価が無い提出は「探索的比較」と明記する。
6. **パネル replay の位置づけを修正する。** `main_candidates` は ICEBERG/GLACIER 導入前の単一エンジンキャッシュで、正解は全て 25 位以内にあるため 40→80 の回収効果は測れない。`prior_replay` は正解分子式を既知とした annotation-only 診断であり、`POP_LAM` の調整実験にはならない。E2(自前の順方向スコア)は「分子式既知・fold-safe 指紋で事前順位付けした PubChem 同一式候補」という条件付き診断として記録する。
7. **提出は E0 と変更 1 件の E3 の原則 2 本。** GPU 週間枠は固定値と仮定せず、アカウント表示で確認する。
8. **表現の修正。** 「順方向モデルは指紋の 4〜5 倍」は条件を揃えた比較ではないので効果量の予測に使わない。FOAM の 95% は探索中に decoy が上回る瞬間の割合。「主催者が prior を近道と見るから外す」は論文の問題提起からの推定であり根拠にしない。GLACIER の重み公開状況は、論文配布版と Kaggle bundle の読み込み実績を分けて記録する。

## 実験の更新

- E1(完了、`experiments/e1_panel/e1_results.json`): 旧キャッシュで生成候補を固定した本来のルール下では、pool 除外シナリオは pop prior に不変、参照あり/参照なしシナリオでは mu 0.05〜0.15 で +0.011〜+0.027(区間は 0 を含まないが、パネルは 249/250 が COCONUT 収載の有名天然物で文献 prior に有利)。PubChem 同一式候補(中央値 882 件)では fold-safe 指紋モデル単独の top-1 7.7%、A+B(パネルを学習)27%、文献 prior のみ 71%。同一式異性体の識別が指紋では弱く、現行の Class 2 性能が文献 prior に依存していることを示す診断。
- E2(実行中): 212 分子 × 上位 200 候補(37,180 候補、予測上限 ~11 万件)で ICEBERG を実行中。評価は window 40/100/200、重み 0.5/1/2、fold0 単独と fold0+0.25·doc の 2 基準。目的は「順方向スコアが同一式異性体の識別と深い順位の回収にどれだけ寄与するか」の診断であり、V18 の TOPN/window 変更の採否判断の材料にする。GLACIER も同じ入力で続けて実行する。
