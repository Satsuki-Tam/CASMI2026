## 2. 仮説と、いま走らせている診断

**仮説 H1(prior の体制差)**: 隠しテストは「よく文献に載った天然物」で、公開系は文献 prior に強く依存して当てている(E1: 250 分子パネルで同一分子式異性体の中から prior 単独 top-1 71%、FP 単独 7.7%)。一方、我々の開発集合 B(GNPS 天然物)では prior 単独 top-1 21% で、融合重み λ=0.5 も LambdaRank の prior の使い方もその体制で決まっている。→ 本番では prior を過小評価している可能性。
**仮説 H2(クラス 1 の照合)**: 公開系はライブラリ近傍一致を exact に近い形で優先(クラス 1 ≈0.95 と推定)。自前は固定規則で C1 視点 0.58、学習で 0.82、保険 libpri で 0.79。

診断(Spark 実行中、`spark_panel_chain.sh`): enveda-np-examples 250 分子(timsTOF、天然物、全分子に他ライブラリ参照あり、Codex 007 で「FP/参照/prior の限定診断」に許可)を B1 v2 の特徴表に通し、(a) 固定規則の prior 重み λ ∈ {0.5, 1, 2, 4}(ICE あり/なし)、(b) libpri τ 0.8/0.9、(c) `rank_v2` の learned / insurance / fixed を公式 scorer で、C2(identity を隠す)と C1(他ライブラリ参照)で測る。GL/ICE は MSG 汚染のため参考値。

## 3. 意見がほしい点

**Q1** LB 0.334 と E0 0.464 の差 0.13 の読み方。「クラス 1 の照合」「prior の体制」「候補生成」のどれが主因かを、手元で切り分ける最短の実験は何か(パネル診断で足りるか、他に必要な対照は何か)。

**Q2** H1 が当たっていた場合(パネルで λ を上げると大きく改善する場合)、(a) 固定規則の λ をパネルで決め直す、(b) LambdaRank の学習データにパネル様の分子を加える/prior 特徴の重みを制約する、(c) 本番に近い分子集合で開発集合を作り直す、のどれを優先すべきか。パネルは forward モデルが学習済みという汚染があるので、prior/参照/FP の結論に限定する前提。

**Q3** H2 への対応として「公開系のライブラリ照合の作り(近傍一致の優先規則)を B1 に部品として取り込む」ことの是非と、評価の仕方(C1 視点の参照は他ライブラリのみとしているが、本番では Enveda 自身の過去測定が train にある分子もあり得る。この条件をどう模擬するか)。

**Q4** locked 開封の扱い。候補 M1/M2 は LB 0.334 の体制で作られたもの。パネル診断で λ や照合規則を変える必要が出た場合、開封を延期して候補を作り直すべきか、それとも登録済みの M1/M2 で一度開き、改訂版は新しい未使用集合(locked 2)で確認する方がよいか。

**Q5** 提出の運用。本日残り 2 回、M1 の採点待ち。M1 が 0.464 を下回っても、M1 の保険(submission_fixed.csv、libpri τ0.9)を提出して「保険 vs 本命」の LB 差を観測する価値はあるか(手元の C1 視点では保険 0.79 vs 学習 0.82、C2 では学習 +0.075)。
