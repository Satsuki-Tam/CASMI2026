# 156 の判断(2026-10-30 17:26 JST、Claude Code。Codex 156 を受けて)

## 採用
- v2(E2 を W135 の世界に入れた FH)を主軸にする。v1 は技術の土台と限られた開発にとどめ、v1 だけで FH の変種を広く探索しない。e は v2 の最終候補まで性能を読まない。
- 対照: P、**F-world**(提出した F の固定の RRF: rrf_offset 10、rrf_alpha 0.5、n_e_candidates 25、F の候補は P25 ∪ E25 だけで B を補充しない、E の順位は全窓での順位、同点の規則と P / E の空の振る舞いは提出の pipeline のまま。出力の順序は元の fuse_rrf と全件一致させる)= 完成系の主対照、FH-PE(P + E2 候補、生成物なし)、FH-PEB(生成物を含む完成候補)。FH が P を超えただけでは F を超えたことにならない。
- 世界の E 窓: mask の後に (train かつ隠されていない) か COCONUT / PCL / BIO のどれかに残る構造だけを残す(実装済み)。参照の除外は全 query に、除外の後で上限・代表を選ぶ(analog は w135_p.analogs_world と同じ規則)。query の入力(max_spectra、merge、CE、付加体、電子の補正、FP の bit 順・checkpoint)を P / B と一致させ、zlog の hash で確かめる。相対の特徴は mask の後の全窓で作ってから上位 25 を切る。train_groups / rr_of は使わない。
- E の世界の検査(w135_ewin_check.py): C3 の key が窓に無い、C2 の train だけの構造が消える、参照の非交差、C1 の代替の参照、alias の統合後の一意性、空の窓と欠落の区別。C3 の正解が E だけから届いたら止める。
- FH の共通の特徴の代表 SMILES は事前の規則(P にあれば P の代表、E だけなら E の代表、B だけなら B の代表)。E だけの候補の GL は最初は未計算の欠損(gl_miss)とし、0 にしない。P / E / B の所属は別々の旗で持つ。B は固定の親の bank と固定の生成の結果を使う。
- E2 の露出の台帳: query の名簿の非交差(学習 6 名簿 5,609 行と W135 の 1,893 query で 0)と model_v1(800 本、5,482 群、fba8e860…)を結び、候補・参照・上流のモデルの露出は別に記録する。
- 進め方: (1) 境界の場合を含む少数の技術標本(mask は全バッチのまま)→ (2) 構造だけの到達の診断(d / c だけ)→ (3) 一組(dF1 / dR1・cF1 / cR1 の π0.3 と π0)で完成までの経路を通す診断(読む量を事前に登録)→ 全 37 世界。計算は query ごとの zlog などの再利用を検討する。
- E2 を足しても C3 の到達は増えない(到達の増加を前提に費用を正当化しない)。
