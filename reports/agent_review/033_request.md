## 提案(結果を見る前に固定したい)
1. T / COCONUT probe がモデル B の区間に入ったら(P_T 0.26〜0.29、P_COCONUT ≤ 0.11)、**full_eval + twin1m_t0.7_m0.1** を一回の Public 比較に出す(今日の残り 1 枠か明日)。読み: Δ ≥ +0.015 → 作業用基準へ(局所のクラス 1 の大きな利得 + 較正 B + Public の向き)、−0.01 < Δ < +0.015 → 昇格せず束ね用に保持、Δ ≤ −0.01 → B のクラス 1 の内訳(G 型の比率)が誤りとして閉じる。
2. A の領域なら twin 系は較正では昇格させない。

## 質問
1. コミュニティの probe を較正の観測に加えることの妥当性。twin の定義(類似の関数・窓・全 train スペクトル vs B1 の shortlist 内の候補ごとの最大類似、DUP 規則、MAX_REF 24)が違う。どの程度の不一致なら観測として使えなくなるか。
2. 25 変種から較正で選ぶ選択の偏り。最も単純な twin1_t0.7 に事前に固定すべきか。
3. twin 系は C2 の保護層(パネル C2 −0.08、W7 timsTOF C2 −0.08)を明確に割る。Codex 028 の規則の下で、Public で較正した class 比を根拠に「C2 層を知りつつクラス 1 と交換する変更」を一回の比較に出してよいか。条件は何か。
4. 隠しのクラス 1 が「パネル型」(既に B1 が当てる)か「G 型」(B1 が落とす)かを判別する証拠。モデル B では重みが C1 hard NP dev2 に多く乗るが、これは他の観測からの推定で脆い。T probe の値はこの二つをほとんど区別しない(train に絞った RR はどちらも ≈ 0.9)。
5. 見落とし: DUP 診断(57645926)との相互作用(隠しのクラス 1 に同装置・同 CE の twin があり 0.98 以上で落とされているなら、DUP を外すだけで twin の類似が上がる)。
