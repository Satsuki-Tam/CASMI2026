# 049b 依頼(049 の追補): 保護規則の偽棄却率(placebo)と、規則の作り直しの提案

作成: 2026-10-27 02:11 JST(Claude Code)。049 の §2〜3 への追加の根拠。数値は `diag/r047_rank_v{4b,8a}_{f1dev,f2dev,p2dev}.csv` と `diag/g048_f1dev.csv` から(ローカル、numpy の再標本化)。

## 1. placebo: 真の効果 0 の変更が、登録の保護(各層 Δ ≥ −0.01)で落ちる確率
- 方法: rank_v8a − rank_v4b の分子ごとの差 d_i の絶対値を保ち、符号だけ無作為(真の効果 0、同じ足跡 = 変わる分子の数と大きさ)にして、047 の保護層(f1dev・f2dev の C1 C/E/F/G、C2 C/D/E/F/G、n ≥ 20 の 18 層)の最小値が −0.01 を下回る確率。
- **結果: 0.923**(4,000 回)。ranker・FPNet・融合のように 15〜25% の分子の順位を動かす変更は、**効果が 0 でも 9 割以上の確率で保護不合格**になる。
- 同じ計算を ggt3(生成の 3 位挿入、足跡が小さい)の足跡で行うと **0.000**。
- 解釈: 現行の保護は、層あたり n 50〜100、層の標準誤差 0.005〜0.024 に対して閾値 −0.01 の点条件を 9〜18 層に同時に課すため、**足跡の大きい変更を構造的に棄却し、足跡の小さい変更(= 利得も小さい)だけを通す**。この 2 日間に通った変更が生成の挿入だけで、ENS2・rank_v8a・FE_new 等の ranker / FPNet 系が全て保護で止まった経緯と一致する。0.48 に必要な規模の変更は、この規則の下ではほぼ採択できない。

## 2. 代案(数値つき)
- 層を集合間でプール(f1dev + f2dev + dev2 = 層あたり n ≈ 300)し、**有意な害**(paired bootstrap の 95% 上限 < 0)だけを保護違反とする場合、同じ placebo の偽棄却率は **0.117**(9 層、多重性の補正なし)。Holm 等で補正すれば ≤ 0.05 程度。
- この規則での rank_v8a(参考、判断の読み替えではない): NP 層は全て非有意(C C1 −0.004 [−0.015, +0.005]、C C2 +0.008 [−0.011, +0.026]、D C2 +0.003 [−0.007, +0.012]、E/F は 0)、**G C1 +0.097 [+0.072, +0.122]、G C2 −0.034 [−0.057, −0.011](有意な害)**。つまり rank_v8a は「G の化学での C1/C2 の交換」で NP にはほぼ中立 — 規則を変えても採用候補にはならない(過去の判断は変えない)。
- 提案する今後の登録の型(049 の §3 C と合わせて):
  1. 主指標 = 隠しに近い層のマクロ(NP の C2 = C/D/E/F、クラス 1 = パネル C1 clean)、プールした n で paired bootstrap の区間を報告。
  2. 保護 = 各層の**有意な害**(多重性を補正)が無いこと + NP 層のマクロの点推定が負でないこと。点条件 −0.01 は記録用に残す。
  3. 確認集合も同じ規則(プール、有意な害なし、主指標 > 0)。
  4. G(合成化学)は別枠で報告し、隠しの化学ではない点を明記(拘束は「有意な害」のみ)。
