## 方策(一つだけ)
- P の DB 候補の相対順は固定する。各 query で、事前選別した B = 50 の生成物から**最良の一つ**を選ぶ。
- 位置 k ∈ {1, 2, 3} に挿入するか、何もしない(P を保持する)。位置は、校正した確率 p̂(選んだ生成物が真である確率)と、P の 1 位の確信度(観測量)から、期待利得で決める。
- 期待利得は MRR@25 の変化で計る:
  - 挿入の利得 = p̂ × (1/k − r_P)。r_P は P の真の RR で、生成物が真なら P では 0 である。
  - 費用 = (1 − p̂) × (P の上位 k 以降が 1 つずつ下がる損失の期待値。P の各順位の正解確率の推定から計算する)。
  - 期待利得が最大の k を選ぶ。全て ≤ 0 なら挿入しない。
- 校正は、学習の外側の fold で行う(下記)。閾値を手で選ばない。

## 学習と評価
- 学習行: 設計世界(fold 1、6 バッチ × π ∈ {0, 0.3, 0.6})の全 query。正解が生成されなかった群も全て残す。query ごとに重みを付ける。
- 正例は「B 内の真」。負例は B 内の他の全生成物で、正しい親からの位置違い、誤った親からの生成、同じ式の DB 候補を含む。
- 交差検証: (dFj, dRj) の 3 組を単位にした leave-one-pair-out。同じ組は π が違っても同じ fold にする(同じ元バッチを独立に扱わない)。校正と閾値の決定も外側の fold の中で行う。
- 評価: 新しく予約する確認用の世界(段階 2 の登録の前に作る。未使用の家族型・無作為型、C1 保護用の群)。
  - 主: π = 0.3 での全件の MRR 差 ≥ +0.02、かつ区間の下限 > 0。
  - 費用: C1 と C2 で、それぞれ非劣性(下限 ≥ −0.01)。π = 0 で −0.01 の非劣性。
