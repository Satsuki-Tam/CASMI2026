**Q1：C2のidentity maskは適切な基本線。寄託・化学系列の偏りは別に測る。**

`analog_probe.py` は真の公式key、queryのraw identityから得られるkey、identity group内のkeyを合わせて除き、`Store.analogs` はそれらをtop-80選択より前に除外します。候補の構造fingerprintと残った参照構造を比較すること自体は、既知構造を探すC2の設定に合っています。実装から直ちに「正解の参照をそのまま見ている」と判断する箇所は見つかりませんでした。

ただし、このmaskが保証するのは指定したidentityの除外です。同じ研究の兄弟化合物、公式identityの対応不備、同一取得が別ラベルで再登録された参照まで一律に除けるわけではありません。提出前の最低限の監査は、C2で返したanalog keyと除外集合の交差が0、query行が0、keyに対応するSMILESの公式identityが整合することです。raw keyだけの比較やMorgan Tanimotoだけの重複判定で代用しないでください。候補側のC2資格、FPNetの正例未見も既存どおり維持します。

「真とanalogの最大Tanimoto < 0.9 が改善の86%」は、近接aliasだけで説明されにくいという補助証拠です。しかし同一シリーズや同じ寄託プロジェクトの類似化合物が <0.9 に入ることはあり、それだけで隠しC2への転用を保証しません。割合の分母も、正の救済量なのか、損失を差し引いたnet RRなのかを記録してください。

感度分析は、重み0.5・候補集合・FP・forwardを固定して次の順で十分です。

1. **queryの `ingest_lib` 別、analogの出所別に損益を見る。** 今回の確認C2はgnps由来が187/336です。library別平均は今回確認した6libraryでいずれも正でしたが、小さい群もあり、独立した6実験という意味ではありません。`ap` を決めたanalogの出所、真とのTanimoto、スペクトル類似、質量差・極性、候補の到達と順位改善を併記すると、どこから利得が来るかを追えます。
2. **queryと同じ寄託libraryをanalogから除く副表を作る。** 除外後に各keyの代表≤3を選び直し、top-80も取り直してください。確認時点の開発版 `b1_baseline/b1_analog.py` の `drop_libs` は、全libraryから先に選んだ代表を検索時に捨てる実装で、他libraryに残る代表を補充しません。これをそのまま使うと、「sourceを除いた効果」に代表選択による追加の欠落が混ざります。凍結提出版にはこの追加flagはなく、提出版を変える必要はありません。
3. **出自情報があれば研究・寄託プロジェクト単位でも確認する。** ingest_libは集約サイトなので、同じ研究が複数libraryに載ることも、同じlibraryに独立研究が混在することもあります。source全体の除外は装置・条件・参照量も変える厳しい感度分析であり、その低下をそのまま隠し性能の低下と見積もらないでください。

この完全なsource除外表が終わるまで、今日の一比較を必ず待つ必要はないと判断します。identity/実装の監査とsmokeを先に満たし、source感度は固定した候補の追加評価として進めてよいです。結果を見て同じ枠の重みや参照条件を変更するための探索にはしません。

もう一つ、凍結版 `b1_analog.py` は既存lib_simのexact/entropyによるDUP除外を呼びません。C1はquery行と真の自libraryを除きますが、他libraryの同一取得・再処理版への制御は別です。clean202/uncertainの既存区分と取得の監査は維持してください。`ap` は候補自身もanalogとして許すため、追加経路の効果には「別構造からの類推」だけでなく、異なる前処理・参照選択での自己一致も含まれます。これは一変更の実験を無効にする理由ではありませんが、利得を全て別構造analogの効果と呼ぶのは避けます。

**Q2：Dの累積未達は、比較提出を止めるほどの理由とは見ません。保護合格への読み替えは不可です。**

現行の点条件に照らすと、D/C2の **FE+ana − M2x = −0.0227** は −0.02 を下回り、不合格です。FEの段で約−0.016を受容済みであることは、累積の損失予算をリセットする根拠にはなりません。区間が0を含むことも、非劣性の確認ではありません。

一方、今回の追加分は−0.0069で、他の主要層は改善し、真に新しいD80でもfold-0上では +0.014（区間は負も含む）です。これらを合わせると、Dで確実に大きく悪化する変更として比較を止める状況ではありません。ただし、新Dは別checkpoint・別分子なので、−0.0227に加算して累積条件を満たしたことにはできません。

提出前の判断記録には「**今回の一比較はDの累積未達を既知のリスクとして許容する。既定保護に合格したとは扱わない**」と書くことを勧めます。昇格までこの例外を認める場合は、その運用判断もPublicを見る前に明記してください。後から都合のよい閾値へ変更したり、Publicが正なのでDの未達を消したりはしません。厳密に028の全点条件を維持する運用なら、この候補は比較後も未昇格のままです。

**Q3：Publicの差は整合性の確認に使い、+0.008を自動採用や有意差の境界にしない。**

`class 2の重み×0.05 + class 1の重み×0.02` は、型・近傍の分布・到達率が転用できると仮定したシナリオです。今回の局所結果から隠しの重みは定まらず、期待値 +0.01〜0.02 を精密な予測とは呼べません。またPublic差のSE≈0.016は、この候補のpaired RR分布を測った値ではありません。他系列の再実行変動や別比較の誤差を代用せず、未知としてください。約1分子という説明も、Publicが約130分子なら0点→1位の一件が約0.008という程度で、一般の順位改善一件の寄与は異なります。

修正した読みは次のとおりです。

| Public差（対0.370） | 判断 |
|---|---|
| +0.008以上など、局所と整合する正 | 暫定採用の候補。凍結版・入力・実行完了を確認し、D例外を事前に認めた場合に限って、局所の証拠と合わせて運用判断する。自動的な保護合格・有意差確定とはしない。 |
| −0.015より大きく+0.008未満 | FEを正式な対照として保持し、anaw0.5を固定した保留候補として残す。小さい正を無効、小さい負を仮説の反証とは扱わず、Publicに合わせて重みを刻まない。 |
| −0.015以下 | 昇格しない。出所・近傍の分布差、参照自己一致、モデルの露出、GL被覆/時間予算を確認する。「隠しではanalogがない/効かない」と原因を一つに確定しない。 |

0.008/−0.015は、採用するなら結果を見ずに固定した運用上の目安です。今回の強い局所の根拠に、小さい正のPublicが整合することには価値があります。その場合でも、Dの扱いを曖昧にしたまま自動昇格する設計は避けてください。保留候補を次の正式な基準に置き換えることもせず、束ねるときはFEおよびM2xからの変更全体を改めて比較します。

**Q4：条件を固定した比較なら、他の四本の得点を待つ必要はありません。**

提出する版を **full_eval・既存のDUP設定0.98・analog_w=0.5・analog_feat=ap** に固定し、T/COCONUT/band/DUPの結果で重み・対象・checkpointを変えないなら、結果を見る前に出してよいです。同じPublicで採点するため統計的に独立な検証ではありませんが、処置と対照は明確です。

DUPと機構上まったく独立でもありません。上記のとおり、analogの自己一致経路はDUPで落ちた候補の証拠を別経路で戻す場合があります。DUPが良かったとして、この版を黙って `dup_sim=1.01` と組み合わせないでください。その組合せは新しい比較であり、二つの差を加えて期待値を作れません。
