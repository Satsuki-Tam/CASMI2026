## 1. 候補 C142(固定)
- **B 内の確率**: `s_i = softmax_i(z_i / T)`。z = 139 の凍結した logit(線形の予測子)。T は正の温度の一パラメータ。各 query で Σ s_i = 1。順位は変えない。
- **query の門**: `r = P(B に真がある | query の要約)`。L2 のロジスティック回帰(C = 1.0)で、query を一単位とし、等重みで学習する。B = 0 の query は r = 0。評価の分母には残す。
  - 入力の要約(固定): log1p(|B|)、z の最大、z の 1 位と 2 位の差、P の 1 位・2 位の得点差、gl_ok、lib_max、log1p(P の list の大きさ)、analog の最大類似度、peer の構造の数。

- **学習のデータ**:

- **凍結**: base は 139 の fit_model(全 18 世界)。T と r は、上の OOF の z で学習した値。係数・T・入力の hash を `s3/calib_freeze.json` に記録する。
