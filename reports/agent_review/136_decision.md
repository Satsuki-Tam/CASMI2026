## 4. 生成器 v2(`experiments/w135/w135_gen_v2.py`。v1 は世界の manifest に記録があるので変更しない)
- **roster**: バッチ・world の分子表・生成の dump・world P が、同じ分子集合で一対一であること(違えば停止)。
- **peer**:
  - 同じ極性の有効なスペクトル対を少なくとも一つ持つ query だけを候補にする(比較の結果が 0 でもよい。閾値は無い)。
  - 質量差が編集で届くことを条件にする。
  - P の 1 位の構造を**公式 key でまとめて(類似度の最大を残して)から**、異なる構造の上位 10 を取る(同値は hash)。
- **親**: train 親と peer 親を公式 key で重複除去し、由来(train / peer / 両方)を記録する。親の key・由来・類似度は表に保存する。
- **生成物**:
  - 代表の SMILES と raw key は一緒に更新する。
  - 位置は公式 key で判定する: 'top25'(P の top 25)、'in_window'(world の窓の構造の公式 key。b1_world v2 の dump)、'out_of_window'(どちらでもない)。'out_of_window' は **DB に無いという主張ではない**。
  - 各付加体の ±10 ppm の外にある生成物には 'off_mass' を付ける(補助)。
- **B**: B 一覧(公式 key。f.z の降順、同値は親得点、key)とその hash、真の順位を保存する。
- **FPNet の bit 順**: 生成器は、world の manifest にある fp_bits.npy の hash と一致する `--fold_safe` を要求する。3 つのディレクトリの fp_bits.npy は同一(c3869e86…)である。

## 5. reader v2(`experiments/w135/w135_read_v2.py`)と判断
- **検査(停止)**:
  - world の manifest(全ファイルの hash)。生成の meta(world manifest の hash、出力の hash、登録した引数)。
  - (set, molecule) が一対一であること(欠落・余分・重複の全て)。
  - oracle の前提。到達した query では、P の main RR = 0、rP = 0 または > 25、真が P の top 25 に無いこと、真が保存した B にあること、f.z の順位 ≤ B であること。到達 ⇔ 0 < 順位 ≤ B。
  - B は重複が無く、50 以下。C3 の真が P の top 25・窓の公式 key・'top25' / 'in_window' に無いこと。値が有限であること。U = U_C3 + U_DBmiss(全 query を分母とする)。
- **U** は、許された action(真が B にあれば 1 位へ挿入し、他は P を保持する)の到達上限である。方策の利得ではない。
- **区間**:
  - 主: 3 組の (dFj, dRj) を復元抽出し、組内の全 query を保つ 50:50 の設計平均(4,000 回、seed 136)。独立な単位が 3 つしかないので**探索的**と明記する。
  - 補助: バッチ内で家族を復元抽出する(各バッチの peer 環境を固定した条件付きの値)。
- **判断(π3 = 0.3、設計 6 バッチ、arm both、B = 50)**:

  | 条件 | 判断 |
  |---|---|
  | U ≥ 0.04 | INVEST |
  | 0.02 ≤ U < 0.04 | LIMITED |
  | U < 0.02 かつ組の上限 < 0.02 | STOP(**この凍結した生成設定への投資を止める工学的な判断**。母集団の上限が 0.02 未満だという証明ではない) |
  | U < 0.02 かつ組の上限 ≥ 0.02 | UNDETERMINED(今は投資しない。追試は新しいバッチで別に登録する) |

  - **dF4-6 / dR4-6 の拡張規則は撤回する**(追加集合を今は固定できないため)。
- B10 / 25 / 100 / all、arm train、家族・無作為の別、クラス別の到達、真の f.z 順位、到達した真の親の由来は、記述として出す。見た後に主結果と入れ替えない。
