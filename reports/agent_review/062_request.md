## 2. 気になっている系統的な問題(相談したい)
- **評価の FPNet と本番の FPNet が違う**: fold-1/2 の dev/conf は公開 fold モデル(学習データ 8 割、公開レシピ)の表、本番は自前 full_eval(全 train − hold/lock)。050 と 056 は fold-safe の集合で正、dev2(full_eval で未見 = 本番に最も近い regime)では 0〜負。ranker(rank_v4b / v8w)の学習表も公開 fold モデルの特徴で、本番では full_eval の特徴に当てている(train / inference の特徴分布のずれ)。dev2 は n が小さく(層 100)何度も使った集合でもある。
- これを解くには、(a) dev2/locked2 型の「full_eval に未見」の新しい集合を作る(full_eval の hold/lock 以外に未見の identity は無いので不可能)、(b) full_eval と同じレシピで fold-k を除いた自前モデルを学習する(データ 8 割で公開 fold モデルと同程度の強さになり、full_eval の強さは再現しない)、のどちらも難しい。どう扱うべきか。
