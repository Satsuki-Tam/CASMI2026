### 1.3 崩壊の機構(推論時プローブ `b1_learned_probe.py`、`diag/probe_panel_rank_v2.md`)
- 学習が負け・固定が勝つ 105 分子: 真は in_train=1、**lib_nref 平均 23.5**、lib_sim 0.79、pop 18.8。学習 1 位候補は in_train 0.13、lib_nref 1.0、lib_sim 0.05。
- LightGBM 寄与(真 − 学習 1 位): **lib_nref −0.62**、lsynonyms −0.25、z_gl −0.28、z_fp −0.28 / lib_margin +0.86、lpmid +0.47、lib_sim +0.17。
- 推論時に特徴を 0 にする ablation(再学習なし): lib_nref・in_train を 0 → **0.588 → 0.822**;参照特徴を全部 0 → 0.849(= 固定規則水準);prior を 0 → 0.833。C2 側は counts を 0 にしても 0.914 → 0.903。
- 真の lib_nref 区分: [21,100] の 229 分子で 学習 0.585 / 固定 0.886 / lib 0.925。
- 原因の解釈: 学習行の 78% は C2 view(真の参照を全て隠す)で、そこでは「参照を持つ候補 = 必ず偽」。C1 view(22%、他ライブラリ参照のみ)の真は参照数が少なく類似も中程度なので、「参照多数 → 偽」の規則を打ち消せない。開発 C1 集合の真の lib_nref は [1,5] 72 / [6,20] 161 / [21,100] 24 で、パネル(229/250 が [21,100])とは体制が違う。
- 開発集合では逆に学習が C1 を大きく改善(eval 群 0.82〜0.83 vs 固定 0.45〜0.47)していたため、開発集合だけでは見えなかった。

### 1.4 参照優先規則の分子別 ΔRR(`diag/libpri_delta_dev.md`, `libpri_delta_panel.md`)
- C2 view(真の参照なし): lib_max ≥ 0.9 の候補が真であることは**一度もない**(A 19/B 11/パネル 5 分子)。libpri(0.9) の損失 A −0.005 / B −0.005 / パネル −0.004、libpri(0.8) は A −0.019 / B −0.009 / パネル −0.022。

## 3. 意見がほしい点

**Q1** 機構の読みと修正方向(counts 除去 + C1 比率の引き上げ)は妥当か。lib_sim > 0 自体が C2 行で完全な負ラベルになる問題は残る(ablation で no_sim 0.631 > learned 0.588)。これに対し (a) C2 行では参照特徴を学習に使わない(C2 行の lib 系特徴を全て 0 にして学習、参照の使い方は C1 行だけから学ぶ)、(b) 「同ライブラリ・同装置の独立取得を参照に残す」C1-all view を追加して真の高類似・多参照の例を作る(特徴再計算 ~1 h + 再学習)、(c) 推論時の二体制切替(lib_max ≥ θ なら libpri(0.8,0.2) > 固定、そうでなければ学習)— の優先順位はどうか。今夜は (b) まで踏み込むべきか。

**Q2** 隠しテストのクラス 1 分子はパネル体制(著名化合物、参照多数、類似 0.6〜0.95)に近いと見るべきか。E0 の参照処理(lib_max ≥ 0.9 で main list 維持)がクラス 1 で ≈0.95 と推定されることと、パネル C1 で公開 main list 0.964 であることは整合する。この想定で、固定規則に lib 項(例: S + 1·z(lib)、または libpri(0.8,0.2))を入れることは、保険としてだけでなく本命の一部として正当化できるか。

**Q3** 再登録。011 §4 の「候補数を増やさず、新版・保険・比較規則を開封前に再登録」に従い、M1 → M1′、M2 → M2′ に置き換える案: M1′ = v2 特徴表(GL+ICE)で rank_v4 相当の再学習(ICE あり)、M2′ = rank_v4b(ICE なし、候補 2 倍)。保険は両方 libpri(0.8,0.2) > 固定へ変更(C1 集合 +0.16、C2 損失 ≤ 0.02)。採用規則は 010 のまま(C2 は A/B 別の paired 差、C1 損失 ≤ 0.02、差 < 0.01 なら時間の短い方)。この置き換えに反対か、M1 は旧登録のまま残す方がよいか。

**Q4** 提出運用(09:00 JST にリセット、2 回/日)。M1 の採点はまだ出ていない(0.334 を下回ればクラス 1 崩壊が隠しテストでも起きた示唆、上回れば C2 の利得が勝った示唆、と読むのは妥当か)。朝の 2 回は (i) M2′ 本命(ICE なし、約 3 h)、(ii) 保険 libpri(0.8) version、で良いか。E0 0.464 を基準に ±0.02 の運用閾値は維持。

**Q5** パネルの C1 view 構成の妥当性確認。パネルは「他ライブラリ参照」を残しているが、真の参照数が平均 224(lib_nref 23.5)と極端に多い。これが隠しテストの代理として過大(著名化合物に偏る)である可能性と、それでも学習融合が固定規則を 0.26 下回ることの重みをどう見るか。
