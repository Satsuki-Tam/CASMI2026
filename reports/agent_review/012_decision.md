## 2. 採否

| 論点 | 判断 |
|---|---|
| Q1 修正の優先順位 | 採用: **(c) 切替規則の小さな比較 → (b) C1-all は取得独立性の監査後 → (a) は見送り**。切替は「GL 被覆不足 または 参照優先が発火 → 保険リスト、それ以外 → 学習リスト」を 1 つの提出関数として実装(`b1_locked_eval.py` の `switch` 出力、probe の `switch` 行)。同じ θ を全集合に適用し、C1 救済 / C2 損失を paired で測る。真のクラスや正解の参照数は切替に使わない。 |
| Q2 隠し C1 の体制 | 全体をパネル型とは仮定しない。参照規則の本命化は混合条件(開発 A/B の C2 と C1 集合・パネル)での損益確認が条件。`S+z(lib)` は未検証のまま採らない。 |
| Q3 再登録 | **v4b をそのまま M2′ として確定しない**。旧 M1(rank_v2、`run_locked_v2`、τ0.9)は凍結対照として残す。M2′ は、参照選択修正後の表で再学習したモデル(rank_v5a/b のうち、eval 群 A/B の C2 損失と C1 集合・パネル C1 の救済を見て決める)+ 切替規則の採否、で 1 本に絞る。M1′(ICE あり再学習)は今回足さない。 |
| 保険 τ | τ=0.9 を既存対照として維持。τ=0.8 は変更案として比較(A/v3/C2 −0.023、パネル C2 −0.022 で「C2 損失 ≤ 0.02」が点推定でも一律に成立しないため昇格させない)。`locked_open_v4.sh`(M1x/M2x、τ0.8)は破棄し、確定後に書き直す。 |
| 採用規則 | A/B 別 paired 差・C1 許容損失 0.02・時間比較を維持。加えて、参照が多い群 / 少ない群で固定・保険に対する差を開発段階で確認してから候補を固定する(probe の lib_nref 区分表に保険・切替列を追加)。改訂後のパネル値は独立な最終検証と呼ばない。 |
| Q4 LB の読みと朝の提出 | M1 の LB 値を C1/C2 の寄与に分けて読まない。±0.02 は調査の運用閾値のまま。朝の 2 枠: 完成した M2′ が比較と提出経路の確認を通れば本命を提出;もう 1 枠は比較目的を事前に決めた保険(τ0.9 既定)か、根拠が揃わなければ温存。可視実行の約 3 時間を隠し再実行時間とは扱わない。 |
| Q5 パネルの重み | パネルの絶対値・悪化幅を隠しテストへ転写しない。ただし「構造・参照が十分ある既知分子で順位を大幅に壊す」現象は無視せず、M2 系で解消する。追加診断は共通の参照予算での再サンプリングで行い、真候補だけ参照を減らす操作はしない。 |
