## 3. 提案(優先順、意見を求める)
1. **fallback 分岐の出力は、GL 特徴なしで学習した専用 ranker(rank_v4b と同じ表・同じ drop、GL 列を除いた特徴集合)に置き換える候補を作り、E/F(dev2)とパネル 34 分子・両 view で、保険・learned(GL 欠損)・専用 ranker を同じ分子で比較する。** 採用規則は 015 と同じ(各集合 paired、保護集合はパネル fallback 34 と G)。母集団で符号が逆なので、片方だけで決めない。
2. **timsTOF query のクラス 1(G 型)**: 学習表に「timsTOF query + 他ライブラリ参照」の C1 行を追加する。候補源は fold 0 の enveda-180 で ≥2 ライブラリの残り(適格 333 group − dev2/locked2 200 = 約 133 group)。足りなければ fold 0 制約を ranker 学習行だけ緩める案(FP 特徴が楽観的になる副作用あり)— 可否を聞きたい。評価は dev2 G(開発)と locked2 G(最終 1 回)。
3. **lib の信用度を条件付けする guard**(装置不一致・参照少のときに τ を下げる等)は、2 の学習で解決しない場合の次善。
4. E0 自前実行の段階表が出たら、上記の層(E/F/G/パネル fallback)で E0 がどう振る舞うか(E0 は forward 不在でも engine と PubChem チャネルを持つ)を先に見る。
