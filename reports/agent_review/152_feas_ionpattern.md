# 152 付随の実現性の確認(記述。判定・採否には使わない)— 極性の観測の型を、構造の証拠として使えるか

作成: 2026-10-30 14:35 JST(Claude Code)。結果を読む前に、読み方を固定する。

## 動機
- Enveda の timsTOF の取り方では、分子ごとに「正・負のどちらの極性(どの付加体)で観測されたか」が変わる(enveda-180: 正のみ 59%、両方 37%、負のみ 4%。パネル: 両方 52%、正のみ 41%、負のみ 7%)。
- 観測の有無は、構造の酸性基・塩基性基による電離のしやすさで決まる(物理の情報)。いまの P / E2 は、分子ごとの観測の型を候補の証拠として使っていない(集合の定義にだけ使っている)。
- FP・GL・ライブラリ・人気度とは独立な情報なので、152 の問い 1(未使用の証拠の型)の材料になる。

## 方法(固定)
- 観測の型: train_meta から、enveda-180 と enveda-np-examples(パネル)の行のうち、隠しテストの 10 付加体で、base peak ≥ 1000 の行だけを使う。分子ごとに has_neg(負の行がある)、has_pos。
- 構造の特徴: RDKit の記述子(logP、TPSA、供与体・受容体の数、電荷など)、酸性基・塩基性基の数(SMARTS)、Morgan の数(半径 2、1024)。
- モデル: LightGBM の二値分類で has_neg を予測。enveda-180 の分子を inchikey14 の hash で 5 分割し、分割の外で予測する(OOF)。パネルの予測は、enveda-180 の全量で学習したモデルで行う(パネルの分子が enveda-180 にもあれば、その分子を学習から除く)。
- 読む量:
  1. enveda-180 の OOF の AUC。
  2. enveda-180 の中の同じ分子式の組で、has_neg が食い違う組の、正しい向きの割合(異性体の識別力)。
  3. パネルの AUC(合成化合物から天然物への移り)。
  4. パネルの各分子について、COCONUT の同じ分子式の構造(正解を除く)を囮にし、観測の型の対数尤度が正解より低い囮の割合の平均(0.5 が無情報)。

## 読み方(結果の前に固定)
- 3 の AUC ≥ 0.75 かつ 4 ≥ 0.60 → 新しい証拠の型の候補として Codex に出す(E2 / P の特徴、または融合の項。登録した比較で測る)。
- それ未満 → この線は閉じる(記録だけ残す)。
- 限界: パネルは 250 分子で、隠しテストより人気の高い分子に偏る。隠しテストの付加体の取り方が、パネル・enveda-180 と同じだという保証は無い。
