## scientific_uncertainty(実験で決める。検査を足して先送りしない)
- 世界の再現性(a)は「一つの変化の向きと大きさが整合した」補助的な証拠まで。今後の +0.01 が Public に同じ量で移るという校正には使わない。
- **撤回**: 「余地 0.18」とクラス別の余地(C2 0.089 / C3 0.068 / C1 0.022)は、1,198 query の到達と 398 query の MRR を混ぜた計算だった。基準の読みで、同じ主集合 S の上で headroom_U2(S) = mean 1[truth ∈ U2] − mean RR(F) を出し、三群(正解が F の上位 25 / U2 にあるが F の上位 25 の外 / U2 の外)に分ける。これは「到達した正解を全て 1 位にできたとき」の上限で、学習で得られる量ではない。
- C3 だけの上限: (360 / 1,198) × 0.225 = 0.0676(楽観、C1 / C2 を傷つけない仮定)。+0.086 を C3 だけに期待しない。C1 / C2 の順位と、必要なら候補の被覆も要る。
- 被覆の分解: 「E の全窓にあるが U2 に無い」と「全窓にも U2 にも無い」の交差集計を、基準の読みと一緒に dev だけで出す(前者なら shortlist、後者なら窓・源・生成の問題)。
- 117 query の「E 源の外」は「C1 / C2 の正解がその query の E 窓に無い」で、窓の条件で外れた場合も含みうる。「DB に無い」とは呼ばない。
- 最小の判別(基準の後): seed 11 の OOF で F、固定の FH-PE、FH-PEB、FH-PEB の得点から PE の資格だけ残した順位(同じモデルの反実仮想、記述)を比べ、損失の場所(DB と生成物の競争 / 挿入の判断 / PE の中の順位)を分ける。
