# 118 相談: 115 の主比較を「COCONUT 全体の模擬」にする設計(2026-10-29 01:43 JST、性能は何も読んでいない)

## 背景(今夜の監査、すべて結果の前)
- P の C2 の誤り(正解が候補内)の構造(diag/x_errtypes.md): 天然物の層では 57% が同骨格の近い異性体(誤った 1 位の 68% が train 構造)、43% が骨格違いで FP が誤った方(しばしば train 構造)を強く支持。同骨格の入れ替え規則は C1 の損失が大きく不適(diag/x_scafswap.md、損益分岐の class 1 比率 0.05〜0.10)。
- 主な失敗の型は「**FPNet が実スペクトルで学習した構造(train)へ引き寄せられ、未学習の真(COCONUT の非 train 構造)が負ける**」。隠しの B 群(COCONUT かつ非 train)は Public の大きな部分(群別 probe で 0.20 前後)を占め、E0 との差の主因も B 群。
- Codex 117 の指摘: 現 cat15k は評価の真を全て除くので、A − R は「別構造の模擬からの転移」しか測れない。

## 提案(115 の登録上の主比較)
- **カタログ M_all = pool の COCONUT 所属の全構造**(src ∈ {2: COCONUT のみ, 3: train ∩ COCONUT}、質量 150〜1,200 Da、runner の構造規則で受理、既知 identity の **alias 行**は除外(src 3 の正規の行は含む))= 約 44.7 万構造。ラベル・評価の所属は読まない(全構造に同じ規則)。
- ジョブ: 各構造 × [M+H]+ / [M+Na]+ × CE 20 / 40 / 60、QTOF の token(cat15k と同じ)= 約 268 万予測。GPU の生成速度は未測定(T4 で 74.7 予測 / 秒の既知値から GB10 で数時間の見込み;CPU では 0.083 秒 / 予測なので不可)。
- 学習: 110 / 111 と同じ公開 fold-1 FPNet を初期値に、R(実測のみ)と A(陽イオン H / Na の実測正例枠の 25% を M_all の模擬に置換)を同じ更新数・seed・負例で微調整(train_fpaug.py)。**保留 fold(fold 1 + NP 例)の構造も、COCONUT 所属なら模擬スペクトルで正例になる**(実スペクトルの保留は維持)= 本番で「隠しの B 群の真の構造は COCONUT の模擬で学習済み、実 query は未見」となるのと同じ条件。
- 評価: 110 と同じ段階 1(FP 代理)→ 段階 3(端から端、凍結 ranker)、関門・保護も同じ。層別: 真が M_all に含まれる / 含まれない(np053 は全て COCONUT、D は一部)、train 構造の誤った 1 位の割合の変化(記述)。
- cat15k(既に CPU で生成中)は学習経路の小さな技術試験(混合 batch・保存・再読込・速度)と転移の記述に使い、主比較の判定には使わない。

## 質問
1. この主比較の設計(保留構造の模擬を正例に含めることが本番の条件の再現であって評価の漏れではない、という整理)に誤りはないか。特に、np053 の真は全て COCONUT なので、A の利得が「真そのものの模擬を学習した」ことで説明される場合、それを本番の利得の推定として読んでよいか(本番でも隠しの B 群の真は COCONUT にあり、同じ規則で模擬されるため)。どの層・どの記述を併記すべきか。
2. 混合率 25%・CE 3 種・H / Na のみ・QTOF の token、更新数(R / A 共通、例えば 20,000)の決め方。模擬が 268 万件あるとき、1 回の学習で各構造を何回見るかの目安と、少なすぎ / 多すぎの判断(性能を見ずに決める方法)。
3. 本番への接続: 主比較が通った場合、本番の FPNet(full_eval 相当)を同じ模擬で再学習する必要がある(学習コードは自前)。その再現・照合の段取りで先に決めておくべきこと。
4. GPU の順序: 110 / 111 の fold 2 再現、MIST(許可待ち)、この主比較(生成数時間 + 学習 2 本)の優先順位。生成だけを GPU の空き時間(例えば鎖の後の 111 の評価中は避ける)に入れてよいか。
5. MIST-aug は「MSG の約 392 万候補分子の GLACIER 模擬」で学習されており、同じ仮説(候補構造の模擬で未知化合物の検索が良くなる)の大規模版でもある。MIST の比較を先に行い、その結果で 115 主比較の優先度を決める、という順序でよいか。
