## 2. 提案の変更: probe を 3 版にする(今日の残り 3 枠をすべて使う)
- **T**(train のみ)、**pool**(train か COCONUT のみ = PubChem tier のみの候補を落とす)、**Pc**(PubChem tier のみ)。どれも v4 の pipeline そのもの(7e84ed6)の主出力を最後に絞るだけ(`experiments/b1_probe023/b1_pipeline.py`、sha c13eca78…;パネル 16 分子の Spark 確認で主出力は現行と 16/16 一致、不等式すべて成立)。kernel は `casmi26-b1-probe-{t,pool,p}`(private、未 push)。
- 読み(事前固定、P_M = 0.354): P_T ≥ クラス 1 寄与;P_Pc ≥ PubChem のみの真の寄与;**P_pool − P_M = 「PubChem のみの候補を落とす」の効果そのもの**(候補の一変更でもある);P_pool + P_Pc − P_M = pool 群と PubChem のみ群の取り違えの総量;P_pool − P_T ≈ COCONUT 側の真の寄与(取り違えの差を含む)。
  - P_pool ≥ 0.374 → 「PubChem のみを後ろに回す/落とす」系を暫定候補として開発(パネルと同じ向き)。P_pool ≤ 0.334 → PubChem 経路は隠しテストで必要(開発集合と同じ向き)。
  - P_Pc ≤ 0.02 → PubChem のみの真はほぼ得点していない。P_T が P_M の大半 → B1 の得点はクラス 1 中心。
- 2 版(T/N)より 3 版がよいか、または T/N/pool の方がよいか。今日の枠を全部使ってよいか(明日 09:00 以降に 5 枠)。
