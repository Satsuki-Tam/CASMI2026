## 4. E2b(汚染のない順方向モデル診断、実行中 → 結果を追記)

設定: (A) enveda-180 identity fold 0 かつ MSG 非収載かつ [M+H]+ を持つ 200 分子(timsTOF・未知分子・合成化合物)、(B) gnps/riken/mona/massbank/msdial の MSG 非収載 200 分子(天然物化学・他装置)。候補 = PubChem tier ±10 ppm 窓の同一分子式構造(InChIKey14 重複排除)から正解 + 最大 99 件をランダム抽出(正解が PubChem 窓に無ければ明示的に追加)。正モード m/z に −0.000548 Da の電子質量補正(Killian 10-13)。評価は順方向モデル単独(ICE / GL / z 和)の順位 vs ランダム。

結果(順方向モデル単独の順位、MRR@25 / top-1、分子単位ブートストラップ 95% 区間):

| セット | デコイ | ランダム | ICEBERG | GLACIER | ICE+GL(z 和) |
|---|---|---:|---:|---:|---:|
| A: timsTOF 未知分子(200、正解が PubChem にあるもの 191) | ランダム 99 | 0.039 | 0.864 [0.822, 0.901] / 79.5% | 0.894 [0.859, 0.927] / 83.5% | 0.890 / 82.0% |
| A: 同上 | 正解に最も近い 99(Morgan Tanimoto 上位) | 0.039 | 0.574 [0.523, 0.625] / 40.5% | 0.640 [0.592, 0.689] / 47.5% | 0.629 / 45.0% |
| B: 天然物ライブラリ MSG 非収載(200、gnps 173、正解が PubChem にあるもの 125) | ランダム 99 | 0.088 | 0.753 / 67.0% | 0.759 / 68.0% | 0.793 [0.744, 0.841] / 73.0% |
| B: 同上 | 近傍 99 | 0.088 | 0.591 [0.535, 0.649] / 47.0% | 0.620 [0.566, 0.676] / 49.0% | 0.649 [0.595, 0.703] / 52.5% |

同一候補集合での fold-safe FPNet(各分子を学習に含まない fold のモデル、`dmitriigluzdov/casmi26-fold-safe-fpnet`、eval_ckpt.py の前処理に準拠、最大 8 スペクトルをマージ)との比較(MRR@25 / top-1、`experiments/e2_forward/e2b_fp_results_*.json`):

| セット | FPNet(fold-safe) | GLACIER | z(FP)+z(GL) | z(FP)+2·z(GL) | z(FP)+z(ICE)+z(GL) |
|---|---:|---:|---:|---:|---:|
| A timsTOF、ランダム 99 | 0.847 / 74.5% | 0.894 / 83.5% | **0.924 [0.894, 0.951] / 87.5%** | 0.914 | 0.923 |
| A timsTOF、近傍 99 | 0.589 / 41.5% | 0.640 / 47.5% | **0.736 [0.689, 0.781] / 59.0%** | 0.718 | 0.714 |
| B 天然物、ランダム 99 | 0.760 / 66.0% | 0.759 / 68.0% | **0.835 [0.792, 0.876] / 77.0%** | 0.827 | 0.829 |
| B 天然物、近傍 99 | 0.570 / 45.5% | 0.620 / 49.0% | **0.707 [0.655, 0.757] / 59.5%** | 0.695 | 0.702 |

読み取り: (1) 公平条件の FPNet は同一分子式異性体に対して GLACIER と同程度か少し弱く(E1 のパネル値 7.7% は候補 882 件・天然物・パネル固有の難しさによるもので、100 件の候補では 42〜75%)、(2) 両者は補完的で、等重みの z 和が単独より +0.09〜+0.15 MRR 改善(難デコイで top-1 41〜49% → 59%)、(3) GL の重みを 2 倍にしても、ICE を加えても、等重み FP+GL を上回らない。V18 の最終並べ替え「z(融合スコア)+1.0·z(GL)」という形は正しく、ICE 追加や GL 重み増の変更(E3 候補 (a)/(b))を支持する証拠は得られなかった。

補足: セット A の同一分子式異性体は PubChem 窓内に中央値 2,622 件(p90 13,139)、セット B は中央値 1,448 件。候補は 100 件に打ち切っているので、実運用(数千件)では順位はこれより下がる。セット A は Enamine 系の合成化合物で、隠しテストの天然物とは化学が異なる。順方向モデルの入力は各分子の [M+H]+ スペクトル最大 8 本、ICEBERG/GLACIER は公開 Kaggle bundle(RDKit 2025.03.6、CE バケット 5 eV、エントロピー類似度 0.01 Da / 20 ppm)をそのまま使用。

解釈: MSG 学習版の順方向モデルは、学習に含まれない分子・timsTOF スペクトルでも同一分子式異性体を強く識別する。パネル(E1)の fold-safe 指紋モデル top-1 7.7%(候補 882 件)と候補数は異なるが、識別力の桁が違う。GLACIER は timsTOF では ICEBERG より一貫して強く、併用の利得は無い。天然物・他装置では併用が最良。V18 は順方向スコアを「融合後の上位 40 件・同一分子式グループ内で z(ランカー)+z(GL) の等重み」でしか使っておらず、順方向スコアを Class 2 の主たる異性体識別器として、より多くの同一分子式候補に、より大きな重みで適用する設計が最有力の改善方向と考える。ただし、現行ランカーの構成要素(指紋 + 文献 prior)との同一候補集合上での直接比較は未実施(fold-safe FPNet と v3 コードを取得中で、次の実験で行う)。

## 5. 判断を求める点

1. **E3 の是非**: 本日残り 4 提出。候補 (a) 最終 rerank_row で ICE を全分子に併用(`kernels/e3b-ice-gl-final/`)、(b) TOPN 60→100 + window 40→80(`kernels/e3-candidate/`)。E2b の公平比較では (a) は等重み FP+GL を上回らず(ICE 追加で −0.01〜−0.02)、(b) を支持する証拠も無い(文献 prior 存在下で窓 40 超の利得なし、正解は 96% が上位 25 以内という参加者計測)。したがって **本日は E0 のみ提出し、E3 の設定変更提出は行わない** 方針で妥当か。E0 の実測が出た後に、Private を見据えた「守り/攻め」2 本の設計を改めて議論したい。
2. **今後数日の投資順序**(調査レポート `reports/CASMI 2026 類似コンペ調査.md` 第 8 節と整合): (i) 検証基盤: identity/scaffold fold × 3 クラスシナリオ × MSG 非収載制約、ブートストラップ、素朴ベースライン併走。E2b の候補生成(PubChem 同一分子式・難デコイ)はそのまま Class 2 用の異性体パネルとして再利用できる。(ii) 自前 FPNet(fold-safe 学習キット、Apache-2.0)の 5 fold 再学習で学習コード付きの指紋モデルを確保。(iii) **GLACIER の timsTOF 適応と同一分子式デコイによる対照ファインチューン**(ICEBERG 2.0 は NIST20 で top-1 25→40%、GLACIER 論文も対照学習で検索精度向上を報告)。E2b で GL は公平条件でも最強の単独識別器であり、FP との融合で +0.10〜0.15 を出しているため、GL 自体を強くすることが Class 2 の最大の上積みと考える。ms-pred(MIT)の学習コードを用い、train.parquet の timsTOF スペクトルで学習すれば入賞要件(学習コード提示)も満たす。(iv) 候補・特徴・欠損フラグを揃えた表の上で LambdaRank を学習(FP・GL・ICE・ライブラリ・アナログ・文献を群内 z で)。(v) Class 3 はアナログ編集 + 分子式制約 + 順方向再採点 + 信頼度ゲートで下位枠に挿入。この順序、特に (iii) の優先度と実現可能性について意見を求める。
3. **E2b の設計上の残る懸念**: 難デコイ版(Tanimoto 上位 99)で評価済みだが、実運用では同一分子式候補が数千件(セット A 中央値 2,622)あり、100 件打ち切りは順位を楽観的にする。また、セット A は合成化合物でセット B は他装置という制約がある。これらを踏まえた上で、E2b を Class 2 の開発指標として採用することの妥当性と、改善すべき点を指摘してほしい。
4. ユーザー目標 0.480 に対する現実的な見通しの表現: 本日中の提出で到達する可能性は低く、E0 の実測値を基準に Class 2 の異性体識別(順方向モデルの timsTOF 適応)を数日かけて積む計画になる、という報告で妥当か。
