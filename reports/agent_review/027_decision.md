## 2. 明日の三本の読み(結果前に固定;0.03 / 0.01 は優先順位の目安で有意差の境界ではない)
- 代数(T = train、B = COCONUT かつ非 train、P = それ以外、K = T ∪ B): `P_T + P_B − P_K` = Pc を除いた pool 内で T/B の所属を完全に選んだときの追加回収量;`P_T + P_B + P_P` = 三群の内部順位を固定した所属 oracle の得点;`max(0, M − P_B − P_P) ≤ M_T ≤ min(P_T, P_K, M)`(今回の下限は `max(0, 0.308 − P_B)`)。
- band: `P_26 = mean(1[26 ≤ r ≤ 50] / (r − 25))` = その帯を 1〜25 位へ繰り上げた MRR(帯に真がある割合 q とは `P_26 ≤ q ≤ min(25·P_26, 1)` の関係しかない)。主出力と帯の oracle は `M + P_26`。51 位以降は 0 なので、低い値から到達不足・クラス 3 が主因とは結論しない。

| 診断 | 観測 | 次の判断 |
|---|---|---|
| T/B | P_T + P_B − P_K ≥ 0.03 | pool 内の所属間競合を減らす余地 → 候補ごとの FP 露出・参照証拠の較正を優先 |
| T/B | ≤ 0.01 | 所属を選ぶだけの余地は小さい → 各群の内部順位・到達を優先 |
| band26 | P_26 ≥ 0.03 | 近い順位帯から少なくとも 0.03 の oracle 回収量 → 順位付け改善の根拠 |
| band26 | ≤ 0.01 | この帯の繰上げ得点は小さい(51 位以降と未到達は区別できない) |
| いずれも | 互斥・oracle の不等式から明瞭に外れる | 所属・公式 identity・空出力・版・実行差を先に点検 |
