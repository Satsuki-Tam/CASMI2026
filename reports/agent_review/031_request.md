# 031 報告と相談: 条件ごとの参照支持の監査(仮説を閉じる)と、C1 view の参照 mask の非対称という評価設計の問題

作成: 2026-10-26 07:15 JST(Claude Code)。前回 `030_decision.md`。結果は `030_decision.md` §2、`experiments/b1_baseline/diag/lc_audit.md`。

## 1. 監査の結果(要約)
- 特徴(条件ごとの最大類似の二番目 = lib_sup2、最大との差 = gap、条件数)は正解を使わずに計算(回帰試験: オプション off で表が完全一致、on で既存列が完全一致)。
- 最良一致 c_L が真である確率は 0.6〜0.7 の帯で gap とともに下がる(0.455 → 0.214)が、対称 mask(query の library の参照を**全候補**から除く診断)では 0.500 → 0.357 に縮み、各セル n 14〜22。他の帯では一貫しない。→ 学習へ進めず仮説を閉じる(030 の規則)。

## 2. 評価設計の問題(新しい発見)
- 対称 mask にすると、最大類似 ≥ 0.85 の最良一致が真である割合が 0.69〜0.77 → 0.83〜0.90(パネル + dev2 C + G)。現行の C1 view は「真の query と同じ library の参照だけを除き、デコイには同じ library の参照を残す」。G 型(query = enveda-180 の timsTOF 合成)では、デコイは同じ装置の参照を持てるのに、真は他装置の参照しか持てない。
- 隠しテストのクラス 1 では、query は Enveda の timsTOF の新規取得で、真の train 構造は enveda-180(同じ Enveda の timsTOF)や他 library の参照を持ち得る。局所の C1 view は真から同じ library の参照を消すので、**隠しより真に不利**かもしれない(特に G 型の層と、参照一致を信用する変更の評価)。
- 一方、真の同じ library の参照を残すと、query 自身の取得に近い参照(同じ化合物・同じ装置の別取得)が残って楽観になる。現行の設計はその漏れを防ぐためのもの。
