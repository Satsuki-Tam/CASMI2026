# Problem model(CASMI 2026、v2 のワークスペース、2026-10-30 19:39 JST、Analyst = Claude Code。根拠は CASMI の repo の reports/agent_review/ の番号)

## 1. 目的変数の生成過程
- 隠れた test: 天然物 約 400 分子、timsTOF のスペクトル 約 1,500(1 分子 1〜16、中央値 3)、単同位体質量 157〜1,159 Da、付加イオン 10 種(水の脱離を含む)。評価の単位は分子(query)。最大 25 の構造の順位リストを出し、正解の公式 key(立体を除く → 互変異性の正準化 → InChIKey の先頭 14 文字)の逆順位(MRR@25)で採点する。
- 正解の三つのクラス: C1 = スペクトルの library にある、C2 = 構造の DB(PubChem / COCONUT)にはあるが library のスペクトルが無い、C3 = どの DB にも無い新規の構造。比率は非公開(C3 は 30〜74% の推定がある)。
- 化合物は抽出物のバッチの中で構造の家族として出る。W135 の世界は、バッチの単位でクラスの mask(C1 / C2 / C3)を掛けて隠れた test を模擬する。π3 は C3 の比率(0 / 0.3 / 0.6)。

## 2. 信号の所在
- スペクトル → 指紋(fold-safe FPNet)→ 前駆体の質量の窓の中の候補の検索。分子式はほぼ当たり、DB の経路の 1 位の誤りの 9 割以上は同じ分子式の異性体(P1 の set A、E2b)。
- 順方向のモデル(GLACIER / ICEBERG: 候補のスペクトルを予測して照合)は指紋と相補的(E2b: z(FP) + z(GL) 0.74、単体 0.59 / 0.64)。断片の木(MetFrag-lite、E2)、analog / library の類似度、人気の事前分布(C2 で強い = 文書化の偏り)。
- 二つの独立なエンジンの融合: F = P + E2 の RRF で Public 0.394 → 0.414(+0.020)。世界でも +0.018(158_result_v2_diag)。**効果は到達(+0.009)ではなく共通の候補の並べ替え**。
- バッチの文脈: 同じバッチの peer から変換(糖・メチル・酸化還元・アシル)で作る生成物 B が、C3 の正解に世界で 0.225 届く(U1 = U2 の C3 の到達)。

## 3. train と test の違い
- 装置: train の天然物の化学は riken / gnps / massbank / mona(timsTOF でない)。timsTOF は enveda-180(合成、1.15M)と enveda-np-examples(250)だけ。GL の timsTOF 適応は同じ装置・同じ化学では効くが、天然物には移らない(105 / 134 / 141、止めた)。
- 新規性: C3 の正解は全 DB に無い。train から作る評価は mask(W135 の世界)が必要。見えている test.parquet は train 由来の dummy で、隠れた性質を推測しない。
- Public は約 130 分子(1 分子 ≈ 0.008)。Public は異常の信号としてだけ使う(ハーネスの規則)。

## 4. 評価指標が報いるもの・罰するもの
- MRR@25 は 1 位を強く報いる(1、0.5、0.33 …)。利得は正解を 1〜2 位に動かすことから来る。26 位以下は 0。
- 公式 key の別名(互変異性)や重複は枠の無駄になる。U2 が空の query は 0 点。
- C3 は、生成した構造が正解と公式 key で完全に一致したときだけ点になる。似ているだけでは 0。

## 5. 競合する見立て
### frame-a: 現状の延長
- 固定の候補の宇宙 U2(P25 ∪ E25 ∪ B、100 枠以下)の中で、最終の順位を学習で決める(FH-PEB、62 特徴)。世界の π0.3 の 4 世界では、到達 0.652 に対して F は 0.472。余地は C2 の順位 0.089、C3 の生成物 0.068、C1 の順位 0.022(全体に対する寄与)。主対照は F-world、関門は +0.01(組の下限 > 0)。
### frame-b: 表現の変更
- query ごとの独立な採点をやめ、バッチの中で同時に決める(peer の確かな同定から、家族として整合する候補を押し上げる。NAP / ConCISE 型)。103 の見込みは +0.005〜+0.015、同じ装置のバッチでは偽の辺が多い。
### frame-c: タスク定義の変更
- C3 を別の課題として扱う: DB の候補の確かさから「新規らしさ」を推定し、25 枠を DB の候補と生成物に配分する(枠の配分を MRR の期待値で最適化)。FH v0 は生成物を 1 位に出せなかった(153)。

## 6. 未解決の問い
- 隠れた test の π3。世界の C1 / C2 の MRR が移るなら、Public 0.414 からは π3 ≈ 0.4 前後と読めるが、装置と化学の違いで C1 / C2 の MRR も下がりうる(未確定)。
- 世界で得た「生成物を上位に出す」利得が隠れた C3 に移るか(公開の解法で C3 の工夫が LB を動かした例はまだ無い)。新規の天然物は peer と遠い可能性がある。
- 候補の中の順位の利得は F では移った(世界 +0.018、Public +0.020)。学習した最終の採点器(FH-PEB)の利得も同じく移るかは、v2 の主系と holdout で確かめる。
