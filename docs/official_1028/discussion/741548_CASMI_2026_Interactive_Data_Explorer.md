# CASMI 2026 · Interactive Data Explorer
topic 741548 | by **zyvren** (https://www.kaggle.com/sharif485) | posted 2026-09-15 | votes 6 | comments 0 | https://www.kaggle.com/competitions/enveda-CASMI26-molecule-id-mass-spectra/discussion/741548

Made a data explorer notebook (https://www.kaggle.com/code/sharif485/casmi-interactive-data-explorer) for getting a feel for the data before modelling. 

- It shows an interactive page with 48 molecules from the training set, where you can click through each structure and compare its spectra across collision energies, adducts and source libraries. 

- You can also change the peak filters and watch the similarity score change, or try a little ranking game that uses the same 1/rank scoring as the competition metric.   

If you're new to this competition(like me) or to mass spectrometry data in general, it's an easy way to see what the data actually looks like before writing any code. It only uses training data with known labels, so it's for exploring, not for predictions. Feedback welcome.
