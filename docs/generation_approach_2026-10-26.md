# クラス 3 への到達: アナログ誘導体の生成(2026-10-26、19:11 時点)

## 1. なぜ生成か(本質の整理)
- 隠しテストは約 400 の天然物。クラス 1(train に参照スペクトル)・クラス 2(PubChem/COCONUT に構造だけ)・クラス 3(どの DB にも無い新規 NP)の 3 種。
- B1 の候補は PubChem tier・COCONUT・train の構造だけ → **クラス 3 では構造的に 0 点**。外部推定ではクラス 3 は 30〜40%(未確定)。
- 公開系譜(E0)の engine は「強いアナログに生合成的な変換を当てた誘導体」を既定で生成している(公開の derive.py)。B1 に無かった部品。
- 新規 NP は既知骨格の新しい誘導体(新しい配糖体・アシル体・水酸化位置の違いなど)であることが多い、という天然物化学の経験則が前提。

## 2. 関連研究(方針の裏付け)
- **生体変換による候補拡張**: MINE(Jeffryes 2015、反応規則で代謝物空間を拡張)、BioTransformer(Djoumbou-Feunang 2019)。既知構造に反応規則を当てて DB に無い候補を作る点が同じ。
- **ネットワーク/近縁性の利用**: NAP(da Silva 2018、分子ネットワークの近傍で in silico 候補を再順位付け)、ZODIAC(Ludwig 2020)、TIMA(Rutz 2019、分類学と化学的一貫性で天然物注釈を再評価)、SNAP-MS(Morehouse 2023)。「スペクトルが近い既知物の構造」を手掛かりにする点が本アプローチの親選び(アナログ)に対応。
- **de novo 生成**: MSNovelist(Stravs 2022)、DiffMS(2025)、MADGEN(2025)など。MassSpecGym の de novo の top-1 はほぼ 0 で、「近縁の既知構造を少し変える」方が現実的。
- **アナログ探索**: MS2Query(de Jonge 2023)。B1 のアナログ経路(0.379 に寄与)と同系統。

## 3. 実装(自前、`experiments/b1_baseline/b1_gen.py` v2)
- 親 = スペクトル類似(シフト付きエントロピー類似)で選んだ train アナログの上位 10 構造。
- 目標質量 = query の前駆体 m/z と adduct から求めた中性質量(ラベルは使わない)。
- 編集 = 生合成的な 36 種(水酸化、O/N/C-メチル化、配糖化 Hex/Pen/dHex/GlcA・C-配糖体、アシル化 Ac/Mal/Cou/Caf/Fer/Gal、プレニル化、硫酸化、水素化/脱水素とその逆)、1〜2 段(両順序)。
- **生成物の精密質量を目標と照合**(max(2 mDa, 10 ppm))、一意化・正解判定は公式 key(採点と同じ正規化)。
- 統合: 最良の新規生成物(FPNet の f·z 最大)を、その f·z が主出力 3 位の候補以上のときだけ 3 位に挿入(**gt3**)。

## 4. 評価の設計(Codex と合意)
- **C3 view**: 各分子の C2 候補から真を除いた「真がどの DB にも無い」模擬。親検索は評価集合全体の identity を除外(他の評価分子も未知とみなす)。
- 保護: C1/C2 view(真が DB にある場合)で、挿入によって正解が押し下げられる損失を全層 ≥ −0.01 で制限。
- 開発 → 事前登録 → 一回だけの確認、の手順。生成器の欠陥を直した v2 では、v1 の確認結果を読まずに隔離して確認集合を新鮮に保った。

## 5. 結果
| 規則 | 確認集合の C3(NP 層) | 保護層の最悪 | 判定 |
|---|---:|---:|---|
| gk3(常に 3 位) | +0.031 | −0.0127(3/12 層が −0.01 未満) | 不合格 |
| **gt3**(FP の gate 付き 3 位) | W7 の NP +0.027(別集合での確認) | −0.0011 | **合格 → 10/27 の枠 3 の候補** |
| dv1(派生可能性の加点) | C2 +0.0087 | W7 で C2 が負 | 保留 |
- 提出前の監査: 挿入 1,123 構造のうち公式 key で既知は 2 件(0.18%)、パネル 250 分子で pipeline と評価器が完全一致(alias の gate を含む)。
- 期待値の目安: クラス 3 の比率を 35% とすると Public +0.006 前後(閾値 +0.008 未満の可能性が高い)。小さいが、**クラス 3 で点が取れるかを Public で直接測る最初の試験**。

## 6. 次(大きくするための方針)
1. **第 2 段**: 生成物に GLACIER を付け、DB 側で固定した FP+GL の尺度で比較(事前登録 044、開発中)。
2. **親を DB の近縁構造へ拡張**: COCONUT 等の「編集 1 段分だけ質量が違う構造」を FPNet で選んで親にする(train に参照が無い近縁体も使える)。小さな試行で被覆が 10% → 20%。
3. **クラス 3 の検出**: 自信のある場合だけ 1 位に置けば利得は数倍になり得る(誤検出の損失との兼ね合い)。
4. **新しい評価集合**: identity fold 1 から dev 500 + locked 500 を作成済み(fold-1 FPNet と ranker の両方に未見)— 確認集合の枯渇を解消。
