# 本質の整理(2026-10-27 深夜、Claude Code、03:02 時点)

## 1. 何が成績を決めているか
- 隠しテストは Enveda の天然物 ~400 分子(Public ~130)。クラス 1(公開スペクトルあり)・2(PubChem/COCONUT に構造だけ)・3(どの DB にも無い)。
- B1 の Public は 0.379、E0(公開系譜)0.464、金 ~0.474。B1 の改善は 1 変更 +0.004〜0.009 の規模。
- **クラス 2 の天然物では「同じ分子式の別の天然物異性体」との勝負**になる。スペクトルの証拠(FPNet・GLACIER)は天然物の異性体の間で弱く、勝負は prior(文献上の有名さ)で決まりやすい。COCONUT 収載の正解が 1 位を逃すとき、勝者が「COCONUT 収載・prior が高い・同じ分子式」の三条件を満たすのは GL あり 52.5%、GL なし 84.6%(正解が候補に入った分子に限った条件付きの集計、Codex 053 の再集計)。
- **隠しの正解がどれだけ有名か**が成績を大きく左右する。パネル(Enveda の NP 例 250、隠しに最も近い)は非常に有名で、FPNet を未見にしても prior だけで 7 割が 1 位。開発集合の NP 正解では 2 割。今日の prior-only probe がこれを直接測る。

## 2. これまでの検証方法の問題(今夜見つけた 3 点)
1. **保護規則の検出力**: 「各層 Δ ≥ −0.01」を 9〜18 層に課す規則は、ranker のように多くの分子を動かす変更を、効果が 0 でも 9 割落とす。小さな変更(生成の 3 位挿入)しか通らなかった理由。→ Codex 049b と合意: 開発の screening と採用時の確認を分け、少数の主保護に ε = 0.01 の三状態(害 / 非劣性 / 未確定)で読む。
2. **regime のずれ**: 本番の FPNet は全 train 学習なので、隠しのクラス 1 は「identity 既見」。保護に使ってきた未見の C1 は stress として扱う(Codex 049)。
3. **化学のずれ**: 開発の「NP 層」は正解の COCONUT 収載率が低かった(C 0.38、D 0.17、E 0.42、F 0.65;非収載は非 NP の証明ではない — Codex 053)。そこで調整した重み(GLACIER を強く、prior を弱く)は隠しの NP には合っていない可能性。→ NP 正解だけの評価集合(053)とパネル未見ベンチ(054)を作り、評価の主対象を移す(Codex 053 で相談中)。

## 3. 今夜の測定で分かったこと
- GL の無い分子(NH4 / 水脱離だけの正イオン)に proxy で GLACIER を掛けると、未見の F 層の C2 で **+0.022(fold-1)、+0.067(fold-2、区間 [+0.028, +0.113])**。登録の開発基準を満たす見込み → 新しい確認集合で一回確認してから提出候補へ。
- (Codex 053 で訂正)同じ NP を未見の FPNet で比べると、RIKEN の query は timsTOF より窓内 FP の MRR が −0.078 [−0.115, −0.041](GNPS は −0.028、非有意)。取得条件を含めて差があり得る。
- rank_v8a(学習データ追加)は NP の正解に限ると C2 で +0.005〜+0.018(3 集合すべて正)。

## 4. 0.48 への道筋(仮説)
- (a) 隠しが「有名な NP」寄りなら、B1 の融合が prior を十分に使えていない分を取り戻す(GL の重み、PubChemLite、prior の重み)— PU ベンチと NP 正解集合で選び、確認後に Public。
- (b) 有名でない NP が多いなら、NP 異性体の間の証拠を強くする(FPNet の ensemble・ICE・MIST、NP 正解で学習した ranker)。
- (c) どちらでも効く小さな改善を積む(GL proxy、生成 ggt3t)。
- (d) E0 との差の出所を Public の一対 probe(今日の枠 4・5)で確認し、差の大きい経路を優先する。

## 5. 追記: クラス 2 は「選択によって有名でない」可能性が高い(推論、未検証)
- クラス 2 の定義は「構造は PubChem/COCONUT にあるが、公開スペクトルが無い」。よく研究された有名な天然物(市販標準品)は公開スペクトルを持つことが多い → それらは**クラス 1** に入る。したがってクラス 2 は、選択の構造上、**公開スペクトルが無い = あまり研究されていない NP** に偏るはず。
- 実際、パネル(全てクラス 1 = 公開スペクトルあり)は非常に有名(prior だけで 7 割が 1 位)。dev の NP 正解(これも公開スペクトルあり)でも prior の top-1 は 2 割。隠しのクラス 2 は prior がさらに効かない側と考えるのが自然。
- 参考: MassSpecGym の検索ベンチでも、スペクトルを見ずに PubChem の既定順(人気順)だけで hit@1 が 50% に達する(「MassSpecGym in the Wild」2026、正解がよく知られた標準品に偏るため)。ベンチの数字の多くは prior の効果を含む。同論文の未補正表では forward model(ICEBERG)の hit@1 36% に対し指紋予測(MIST の MSG 版)は 9.6%。
- 含意: 隠しのクラス 2 で効くのは「有名さ」ではなく**スペクトルの証拠**(forward model・指紋・アナログ)。B1 が強い領域(既見のクラス 1 0.93、有名な NP 0.90)と、隠しで点を落としている領域(有名でない NP のクラス 2、クラス 3)が分かれている、という見立て。→ 053 の NP 正解集合(prior が弱い側)を主対象にするのは妥当で、証拠を強くする手(ICE の再評価 051、FPNet ensemble 058、GL proxy 050)を優先する。
- 出典: [MassSpecGym in the Wild (arXiv 2606.19624)](https://arxiv.org/html/2606.19624)、[MassSpecGym](https://github.com/pluskal-lab/massspecgym)
