## 2. 候補の出典と段階

候補取得は測定中性質量 ±10 ppm の窓(enveda-180 は電子質量補正後)。出典は 3 つで、来歴を別々に持つ。

| 出典 | 内容 | 同一性 |
|---|---|---|
| 公開 v2 pool (`pool_meta.parquet`, 710,701) | src 1 = 学習構造のみ 248,440、2 = COCONUT のみ 436,515、3 = 両方 25,746 | 鍵は公式 scorer key と一致(学習構造 274,186 件で 100%) |
| prvsiyan COCONUT (`coco_*`, 436,389) | v2 pool の COCONUT と 390,918 件重複。**学習構造を除いた COCONUT**(pool src 3 の 25,746 件は含まれない)なので、学習分子である評価正解は決して含まれず、デコイ源としてのみ働く | 鍵は raw InChIKey14(公式鍵との一致 84%)。SMILES から計算し直す |
| PubChem tier (`pc_*`, 105,875,489 行) | 公開パイプラインの PubChem 候補源 | raw 鍵で重複排除し、shortlist のみ公式鍵を計算 |

段階(class-2 の模擬: 正解の「学習構造としての存在」は隠す):

1. `db_present_external` — 正解が COCONUT(pool src 2/3 または coco)か、PubChem tier の理論質量 ±2 mDa 窓に存在
2. `window_external` — 測定質量の ±10 ppm 窓内に外部 DB 由来で存在(raw 鍵一致、または同一分子式候補の公式鍵一致)
3. `truth_in_window_raw` — 3 出典を合わせた窓内(漏斗側の集計)
4. `truth_in_shortlist` — FPNet 上位 K=100 と z(FP)+0.15·prior 上位 K の和集合(公式鍵で重複排除)
5. top-25 / top-1 — 融合規則ごと

`window_train`(学習構造としての窓内存在)は class-1 経路として別に記録し、順位付けでは正解の in_train フラグを偽にする。

## 3. 順位付けの部品

- FPNet: `casmi26-fold-safe-fpnet` の fold 0 のみ(学習コード付き)。マージしたスペクトルから f·z。
- 文献 prior: 公開 `casmi26-pubchem-popularity-prior`(tier 行・pool 行に整列)。pop_public = ln(1+SID) + ln(1+PMID) + 0.5·ln(1+synonyms) + 1.0·NP 所属 + 0.5·寄託源ビット + 0.5·ln(1+LOTUS refs)(公開ノートブック v18 の定義に合わせた)。COCONUT のみの候補は NP=1、他は 0。
- 順方向モデル: GLACIER / ICEBERG(MassSpecGym 重み、評価分子は MSG 非掲載)を shortlist に対して実行。
- 融合: z 和(z は shortlist 内)。prior 単独 / FP / FP+0.15 prior / FP+GL / FP+GL+prior / ICE 追加 / 2·GL。

### 4.4 提出候補 E4(`kernels/e4-pclist/`、make_e4.py で E0 から 4 箇所だけ置換)

v1(GL のみ、09:00 に Kaggle へ push、検証実行のみ)→ ICE 完全版の結果を受けて **v2** に改訂:

1. PubChem 専用チャネルの K: 25 → 100。
2. ICE/GL の入力に lib_max < 0.9 の分子の PubChem リスト全件を追加(隠しテストで各 ≈7 万予測の追加見込み)。ICE_BUDGET 5400 → 7200 秒、GL_BUDGET 4000 → 5400 秒。
3. PubChem リストの再順位: 上位 25 同一分子式 slot 再順位(ICE+GL)→ リスト全体の z(pc_fz) + 2·z(GL) + 1·z(ICE)。
4. ゲート・slot・昇格、base リストの処理、後段の RRF/overlay は不変。

粗い期待値: 公開 LB の class-2 分子が 4 割なら +0.012〜0.016(後段の RRF・slot で希釈されるため不確実)。提出判断は Codex 004 の回答とセット B の方向を見て行う。
