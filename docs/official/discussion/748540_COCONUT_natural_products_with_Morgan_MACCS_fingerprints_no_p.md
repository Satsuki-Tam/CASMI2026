# COCONUT natural products with Morgan + MACCS fingerprints (no pickle)
topic 748540 | by **Aryan Awasthi** (https://www.kaggle.com/aryanawasthiteykik) | posted 2026-10-12 | votes 0 | comments 0 | https://www.kaggle.com/competitions/enveda-CASMI26-molecule-id-mass-spectra/discussion/748540

I’ve shared 436k COCONUT 2.0 natural products, sorted by mass, with precomputed Morgan-2048 + MACCS fingerprints in plain Parquet/NumPy, so there’s no pickle to load and no RDKit needed to use them. The description has a 10 ppm window example and code to add the training structures yourself (they can’t be redistributed).

Dataset: https://www.kaggle.com/datasets/aryanawasthiteykik/casmi26-coconut-morgan-maccs-fingerprints
It matches the outputs of my spectrum→fingerprint model: https://www.kaggle.com/datasets/aryanawasthiteykik/casmi26-spectrum-to-fingerprint-mlp
