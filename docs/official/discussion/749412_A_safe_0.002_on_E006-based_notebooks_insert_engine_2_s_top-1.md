# A safe +0.002 on E006-based notebooks: insert engine 2’s top-1 at rank 2 (0.440 → 0.442, 0.441 → 0.443)
topic 749412 | by **Antriksh Arya** (https://www.kaggle.com/antriksharya) | posted 2026-10-14 | votes -2 | comments 0 | https://www.kaggle.com/competitions/enveda-CASMI26-molecule-id-mass-spectra/discussion/749412

Hi all, sharing a small, robust improvement that works on top of the current public E006 / v7c notebooks.

The observation

The E006 pipeline fuses two candidate engines (engine 1 = v4n ranker, engine 2 = two-ranker BIO+AFIX) plus a PubChem channel. When engine 2's own top-1 disagrees with the final rank 1, who's right? I measured it with masked LB probes: submit a single guess per molecule and a never-matching placeholder (CCO) everywhere else.

Probe (on E006)
Public score
≈ molecules

Engine 2's top-1 only where it differs from E006's #1
0.023
~3 where engine 2 is right, E006 wrong

E006's #1 only on those same disagreements
0.102
~13 where E006 is right

So on disagreements E006 wins ~13 : 3. Swapping engine 2's pick to rank 1 is a bad idea (it scored 0.403), but those ~3 buried answers are still worth rescuing.

The fix: one appended cell

Where engine 2's top-1 differs from the final rank 1, keep the final #1 and insert engine 2's top-1 at rank 2, deduplicating by the metric key.

- It can never lose a rank-1 hit.

- Answers engine 2 got right move up to rank 2.

- The only cost is a one-rank shift of positions 2-25 on disagreement molecules.

The same +0.002 on two different bases, so it looks like a real effect rather than a lucky shuffle.

What didn't help: the same insert for engine 1's top-1 at rank 3 was neutral (0.442). Engine 1 and the PubChem channel rarely hold buried rank-1 answers on public (~1 molecule each, by the same probe method).

One tip on probing

If you run masked probes, never hard-code the visible test size (400). The hidden test has a different number of molecules. A failing assert in the last cell makes Kaggle silently score the previous submission.csv, which can give you a convincing but completely wrong probe result. That cost me a couple of days.
