# [Dataset + Notebook] 139K harmonized MassBank spectra + fingerprints —  ready-to-use reference library for retrieval baselines
topic 741874 | by **Samar Talwar** (https://www.kaggle.com/samartalwar) | posted 2026-09-17 | votes 3 | comments 0 | https://www.kaggle.com/competitions/enveda-CASMI26-molecule-id-mass-spectra/discussion/741874

Packaged 139,744 MS/MS spectra (20,204 unique structures) from public MassBank
records into one clean reference library for this competition — precursor m/z,
adduct, ion mode, full peak lists, plus precomputed Morgan + MACCS fingerprints
per structure. Includes 648 spectra from the actual CASMI 2012/2016 challenge
subsets.

Useful if you're building spectral-matching or retrieval-based baselines and
don't want to write a MassBank parser from scratch.
