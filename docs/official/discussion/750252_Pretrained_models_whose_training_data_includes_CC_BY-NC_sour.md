# Pretrained models whose training data includes CC BY-NC sources (e.g., HMDB)
topic 750252 | by **uki706** (https://www.kaggle.com/uki706) | posted 2026-10-17 | votes 1 | comments 3 | https://www.kaggle.com/competitions/enveda-CASMI26-molecule-id-mass-spectra/discussion/750252

Hi organizers, a quick question on external models. Some public de novo generators (for example DiffMS, MIT weights on Zenodo 15122968, and DualLGD, CC BY 4.0 weights on Zenodo 20281201) were pretrained on structure lists that include HMDB, which is licensed CC BY-NC 4.0. The code is MIT and the weights are free and public. Is using such pretrained weights allowed under the external data and model rules? Thank you!

## Comments (2 top-level)

- **Marie Killian** **[Organizer]** (2026-10-19, votes 0)
  Yes, these weights are allowed. (In 750330, the rules on external data were clarified and HMDB is allowed.). Just please make sure that, for any weights used, the original training code and access to permitted training data are available for your final solution.
