# 検証設計と残る懸念(2026-10-24 13:30 版)

この文書は「何をもって改善と認めるか」の規則と、まだ解けていない弱点を明文化したもの。更新はコミット単位で追う。

## 1. 本番条件(分かっていること)

- 隠しテスト: 天然物 約 400 分子、約 1,500 本、1〜16 本/分子(中央値 3)、timsTOF(Bruker)、10 アダクト(水損失を含む)、質量 157〜1,159 Da。
- Class 1(ライブラリに参照あり)/ 2(構造は PubChem・COCONUT にある)/ 3(新規)の比率は非公開(推定は 3 割〜7 割まで割れる)。
- Public LB は約 130 分子と**推定**(参加者推算。1 分子の最大寄与 ≈0.0077、順位 1→2 なら ≈0.0038)、1 日 5 提出、採点は E0 で約 4.5 時間かかった(観測値、保証ではない)。

## 2. 採っている規則

| 原則 | 具体 | 根拠 |
|---|---|---|
| 分子単位の分離 | 公式同一性(立体除去 + タウトマー正規化 InChIKey14)で identity group を作り、fit / tune / eval を group 単位で分離 | 同じ分子の別スペクトルが両側に出ると類似度検索が自明になる |
| 未学習分子で測る | FPNet は fold 0 固定、fold 0 の分子のみ評価。GLACIER/ICEBERG は MassSpecGym 非掲載分子のみ | E1 でパネル 250 分子の 236 が MSG に含まれ、順方向モデルの評価が汚染されていた |

| 層別報告 | A(timsTOF・合成化学)と B(天然物化学・他装置)を別々に。本番比率を仮定した単一指標は作らない | 003 |
| 視点別 shortlist | C2 の shortlist に C1 参照由来の正解が入らないよう、参照枠は視点ごと | 006(B で 7 分子の混入を検出) |
| 複製参照の除外 | **ピーク列一致群**(同アダクト・|Δprec| < 5 mDa・cleaned ピーク列一致。取得情報が無いため同一取得の証明ではない操作上の定義)は常に除外。**近似重複を疑う群**(類似度 ≥ 0.98)は除外版と保持版を併記。分母は規則ごとに変えず、固定した台帳で比較 | 006/007 |
| 出典なし候補の除外 | C2 視点で、外部出典が無く学習構造としての存在も隠された候補は除く(残すと「出典の無い候補 = 正解」という漏れ) | 006(予備試験で +0.11 の見かけの利得を作っていた) |

| 公式スコアラーで採点 | `src/metric.py`(公式メトリックの複製)で最終値 | 003 |
| LB の使い方 | 1 変更ずつ、方向の確認のみ。増分を予測しない | 005 |

採否(007 で改訂): (1) 機械的条件(候補・特徴・公式出力の parity、分母、欠損処理、時間予算)を満たす。(2) 固定した対照に対する paired delta・効果量・区間を報告し、A/B の一方の小さな負差を直ちに矛盾と扱わない。(3) C1 の保護は事前に決めた非劣性幅 ε で判定。(4) 開封前に主候補・保険候補・規則を固定し、locked で 1 回確認。(5) LB は不整合の大きさと処置の適用範囲を調べる材料で、符号一致を必須にしない。

## 5. Codex 007 の判断(14:05)

優先順位: W7(評価/提出の一致、固定分母)→ W4/W8(参照条件・adduct 層の台帳)→ W1 限定診断(パネル 250 は FP/参照/prior/規則の形の診断、同一 identity の装置差組、A の事前固定した化学層)→ W9(学習融合の比較、identity 単位 bootstrap、単調制約は 1 変種)→ W5(拡大)。W6 は並行。W3 は「DB holdout の C3 代理」の枠組みだけ先に決める。
Class 比率は LB から逆算しない(純検索型なら p3 ≤ 1 − S の上限のみ)。最終提出は開封前に主候補・保険候補を固定。詳細は `reports/agent_review/007_decision.md`。

## W7 parity の結果(2026-10-24 18:30、50 分子 = eval_set A/B 各 25、`spark/jobs/spark_parity50_chain.sh`)

評価器(`b1_features` の特徴表 + 保存済み GL/ICE)と提出パイプライン(評価モード: per-query マスク `--mask_json`、電子質量規約を test 側にも適用)を同じ分子で比較した。

| 項目 | C2 | C1 |
|---|---|---|
| 固定規則の top-1 一致 / 分子別 RR の差 | 50/50 一致 / 全分子 0 | 50/50 一致 / 全分子 0 |
| 正解が shortlist に入るか(両経路) | 0.66 / 0.66、不一致 0 分子 | 0.88 / 0.88、不一致 0 分子 |
| 候補集合が完全一致 / Jaccard 平均 | 62% / 0.991 | 78% / 0.992 |
| prior・所属フラグ(tier/COCONUT/train)の一致 | 1.000 | 1.000 |
| 参照類似の最大差 / ppm の最大差 | 0.015 / 1.25 ppm | 0.015 / 1.25 ppm |

候補集合の差の内訳: (a) 9 分子で窓の unique 数が 1 だけ違う = パイプラインの C2 マスクが「ライブラリにしか無い正解構造」を窓から削除する(評価器は C2 視点で同じ構造を落とすので出力は同じ); (b) 1 分子(ACZWIDANLCXHBM、スペクトル 8 本超)で adduct round-robin の選択が異なり FP が最大 33 違う; (c) 数分子で境界(100 位付近)の候補が 1〜2 件入れ替わる(FP の数値差 ≤ 1.8)。いずれも固定規則の出力(RR)は一致。**合格(注記付き)** とし、600 分子の W7 本番(`spark_w7full_chain.sh`)へ進む。残課題: (b) の query 選択を完全一致させる(make_eval_test の順序を b1_features と同じ関数に揃える)。
