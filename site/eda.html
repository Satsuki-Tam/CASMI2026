1. この課題は何をするのか

入力は 1 つの未知分子について測った 1〜16 本のタンデム質量スペクトル(MS/MS)です。各スペクトルは「分子をイオン化して壊したときに出る破片(フラグメント)の質量/電荷 m/z と相対強度の並び」で、 あわせて壊す前のイオンの m/z(プリカーサ)、イオン化の形(アダクト、例 [M+H]+ はプロトンが付いた形)、正負の極性、壊す強さ(衝突エネルギー、CE)が付きます。
出力はその分子の 2 次元構造(SMILES)を 25 件まで順位付けしたリスト。評価は MRR@25: 正解が 1 位なら 1 点、2 位なら 1/2、…、25 位なら 1/25、入っていなければ 0 点の平均です。 構造の同一性は立体を除き、互変異性体(タウトマー)を正規化した InChIKey の先頭 14 文字で判定します。

下の図は、学習データにある ケンフェロール(左、フラボノールの一種)と、原子の組成がまったく同じ ルテオリン(右、フラボン)のスペクトルです。縦の線が破片、点線がプリカーサの位置(プリカーサ付近は除いて表示)。衝突エネルギーを上げると大きな破片が減り小さな破片が増えます。 異性体どうしのスペクトルは共通する破片が多く、下の表のとおり同じ分子の CE 違いより異性体の方が似て見えることすらあります。この「組成が同じで構造だけ違う候補を見分ける」ことが Class 2 の本質的な難しさで、質量だけでは手も足も出ません。

スペクトル類似度(エントロピー類似度、1 = 同一)値
ケンフェロール 40 eV vs ケンフェロール 50 eV(同じ分子、CE 違い)0.519
ケンフェロール 40 eV vs ルテオリン 40 eV(異性体、同じ CE)0.620
ケンフェロール 50 eV vs ルテオリン 50 eV(異性体、同じ CE)0.412

質量だけでは異性体を区別できない(両方 286.0477)。PubChem には同じ組成の構造が数百〜数千あるため、スペクトルの「壊れ方」と構造の整合(指紋予測・順方向モデル)で絞り込む必要がある。

2. データの中身

学習データは 2,539,608 本のスペクトル、275,810 種類の分子(公式の同一性では 274,195 種類)、11 のライブラリから集められています。最大のライブラリ enveda-180 は主催者が timsTOF 装置で測った合成化合物ライブラリで、 天然物のスペクトルは riken / gnps / massbank / mona などの公開ライブラリにあります(装置は Orbitrap や QTOF)。隠しテストは天然物約 400 分子・timsTOF なので、学習データと装置・化学の分布が違うのがこの課題の特徴です。

テストデータ

公開されているローカルの test.parquet は 400 分子・1,213 本で、スペクトル/分子の中央値 3(最大 9)、アダクト種/分子の中央値 1。 ただしこれは学習データ(enveda-180)の抜き出しで、本番の採点に使われる隠しテストは別物です: 天然物 約 400 分子、約 1,500 本、1〜16 本/分子(中央値 3)、10 種のアダクト(水損失アダクトを含む)、質量 157〜1,159 Da。 ローカル test のアダクト: [M+H]+ 959, [M-H]- 193, [M+CH2O2-H]- 31, [M+Na]+ 22, [M+NH4]+ 4, [M+K]+ 2, [M+Cl]- 2。

3. 3 つのクラスと「候補の漏斗」

隠しテストの分子は、答えがどこにあるかで 3 つに分かれます(比率は非公開)。

Class 1: ライブラリに参照あり

同じ分子のスペクトルが学習ライブラリにある。スペクトル同士の類似度検索でほぼ解ける(公開解法で 0.95 超)。ただし本番は timsTOF、参照は Orbitrap/QTOF が多く、装置差で類似度が下がる。

Class 2: 構造は PubChem/COCONUT にあるがスペクトルは無い

質量から候補を集め(数千〜数万)、スペクトルの壊れ方と構造の整合で順位付けする。同じ分子式の異性体の識別が本質。指紋予測モデル(FPNet)と順方向モデル(構造からスペクトルを予測する ICEBERG/GLACIER)を組み合わせる。

Class 3: どのデータベースにも無い新規構造

候補を生成しなければ 0 点。公開解法でも誰も LB を動かせていない。比率が 3〜7 割と推定が割れていて、到達できる上限を左右する。

Class 2 の典型的な流れ。質量 ±10 ppm の窓に 1 万個の構造があり、同じ分子式だけでも数千。指紋モデルが分子式をほぼ決め(上位 25 の 24 個が正解と同じ分子式)、残る異性体の識別を順方向モデルが担う。

4. 自前ベースライン B1 の処理の流れ

① 候補取得

各スペクトルのプリカーサ m/z とアダクトから中性質量を計算し、±10 ppm の窓で PubChem(1.06 億構造)、学習構造 + COCONUT(71 万)から候補を集める。

② 安いスコア

指紋予測モデル FPNet(スペクトル → 分子指紋の予測、候補の指紋との内積)、文献 prior(PubChem の文献数など)、ライブラリ類似度(学習スペクトルとのエントロピー類似度)。

③ shortlist

FPNet 上位 100 ∪ FPNet+prior 上位 100 ∪ 類似度上位 20 を公式同一性でまとめる(約 115 件)。

④ 順方向モデル

GLACIER / ICEBERG が候補構造から MS/MS を予測し、実測との類似度を出す(重い計算なので shortlist だけ)。

⑤ 融合

固定規則 S = z(FP) + 2·z(GL) + z(ICE) + 0.5·prior(z は候補内の標準化)、または学習した順位付けモデル(LambdaRank)で並べ替え、上位 25 を提出。

検証

学習に使っていない分子を凍結し、「参照を隠す(Class 2 模擬)」「他ライブラリの参照を残す(Class 1 模擬)」の 2 条件で、到達不能な正解を 0 点とする strict な MRR で比べる。
