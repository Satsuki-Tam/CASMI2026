0. 要約

  • 調査: 類似コンペ・ベンチマーク・論文の統合レポート(93 KB、出典 257 件)、全 119 ディスカッションスレッドの一次精査ダイジェスト(ホスト発言 40 件を日付付きで整理)、Codex との 3 往復(000〜002)を完了。先例は CASMI 6 回と MassSpecGym のみで、課題の本質は「Class 2 の同一分子式異性体の識別」と「Class 3 の候補生成」。公開最高系譜の積み上げは CV 未検証、入賞要件(全重みの学習コード提示)も未達。
  • 提出: 公開最高系譜(0.464 構成)の忠実再現を E0 として提出(submission 57567821)→ Public LB 0.464(報告値を再現。金圏下限 約 0.473、首位 0.504)。設定だけを変えた 2 本目は、支持する比較が無いため提出せず(Codex も同意)。本日の残り提出 4 回。
  • 実験の主結果: (1) パネル(E1)では公開パイプラインの Class 2 性能が文献 prior に依存していることを定量化。(2) 公開パネルの順方向モデル評価は MassSpecGym との重複(250 分子中 236)で過大評価の恐れがあると発見。(3) 学習に含まれない分子で、fold-safe 指紋モデルと GLACIER/ICEBERG が同一分子式異性体の識別で補完的であることを確認(timsTOF 近傍デコイ: FP 0.59、GL 0.64、融合 0.74。公式鍵・装置限定で再実行済み)。
  • P1 基準系(08:00〜09:10): Codex 003 と合意した「分子式も正解追加も使わない候補取得 → 公式同一性で採点」の基準系を実装し、未使用の 600 分子(timsTOF 300、天然物ライブラリ 300)で実行。timsTOF では、1 万構造の窓から fold-0 FPNet で絞った shortlist に GLACIER を全体 z 和で融合すると MRR@25 0.465 → 0.685(2 倍重みで 0.708)。公開 Notebook の「上位 25 の同一分子式だけを slot 固定で再順位」規則を同じスコアで再現すると 0.627 で、規則の形だけで約 0.06〜0.08 を失っている。公開 Notebook の PubChem 専用リスト(K=25)の模擬では、E0 の規則(ICE+GL)0.717 に対し K=100 + 全体 z(base)+2z(GL)+z(ICE) が 0.766(+0.049 [+0.021, +0.077])で、fit/tune/eval の 3 群で一致。ICE はこの条件では有効(E2b の結論を訂正)。→ E0 から 4 箇所だけ置換した提出候補 E4 v2 を作成(kernels/e4-pclist/)。提出は Codex 004 の回答とセット B の方向を確認してから判断(提出枠は 09:00 JST に 5 回へ更新)。
  • 次の到達点(Codex 002 と合意): 評価と来歴の修正・凍結 → 学習コード付き FPNet + 凍結 GL の基準系 → 実際の shortlist 上の特徴表と学習融合 → GLACIER 適応の小規模試行 → 生成経路。「数日で 0.480」は断定せず、測定可能な到達点で管理する。

E2: 順方向モデル(ICEBERG / GLACIER)による再スコアリングの診断

設定: パネル 212 分子([M+H]+/[M+Na]+ 正モードスペクトルを持つもの)、同一分子式 PubChem 候補を fold-safe 指紋で順位付けした上位 200 件(37,180 候補)に対し、MassSpecGym 学習版 ICEBERG と GLACIER(公開 Kaggle bundle、RDKit 2025.03.6、ローカル RTX 5070 Ti)でスペクトルを予測しエントロピー類似度を算出。窓 40/100/200 と重み 0.5/1/2 で融合し、MRR@25 を比較。

結果(パネル、ICEBERG 212 分子 37,180 候補を 1,067 秒、GLACIER を 623 秒で予測、RTX 5070 Ti):

読み取り: (1) 順方向モデル 2 本の併用は単独より一貫して良い(窓 100 で ICE 単独 0.372、GL 単独 0.357、併用 0.419)。(2) 文献 prior が効いている状況では窓を 40 から広げても利得はほぼ無い(正解は既に上位 40 に入っているため)。文献 prior 無しの状況(文献の少ない分子)では窓 40→100→200 で +0.03、+0.03 と積み上がる。(3) 順方向モデル単独は文献 prior を下回る(パネルの偏り)。

重大な注意: パネル 250 分子のうち 236 分子が MassSpecGym に収載され(204 分子は MSG の train fold)、MSG 学習版 ICEBERG/GLACIER はこれらのスペクトルを学習済み。したがって上の数値は記憶による水増しを含み、未知分子への効果量としては使えない。これを受けて E2b(MSG 非収載の分子)を追加実施。

E2b: MassSpecGym 非収載分子での順方向モデル診断(v1。Codex 002 の指摘により v2 で修正・再実行済み。v2 の表を正とする)

E2c: 端から端の Class 2 相当漏斗診断(分子式なし・正解追加なし、experiments/e2_forward/funnel/)

Codex 003 が求めた P1 の予備版。E2b v2 と同じ 400 分子(学習ライブラリに公開スペクトルがある分子を Class 2 の代理として、参照は使わない)について、実測 [M+H]+ プリカーサ(電子補正済み)から中性質量を求め、PubChem tier の ±10 ppm 窓にある全構造(分子式で絞らない、正解を追加しない、raw InChIKey14 で重複排除)を候補とし、fold-safe FPNet(各分子を学習していない fold のモデル)で全候補を順位付け、上位 100 件を GLACIER / ICEBERG で再スコアして、公式 MRR@25 相当(raw 鍵で正解照合)を測った。

4. 現時点の結論

  1. 本質的課題は Class 2 の同一分子式異性体の識別と、Class 3 の候補生成であり、調査(CASMI 史、MassSpecGym、公開パイプライン、全ディスカッション)と自前の実験(E1/E2/E2b)が一致している。Class 1 は参加者報告でライブラリ検索 0.9 超だが、新しい基準系でも同じ性能が出るかは別条件(同一測定・複製を除いた参照検索)で測る。
  2. 順方向モデル(GLACIER)と指紋モデルは同一分子式異性体の識別で補完的。timsTOF(CE 既知)の未見分子では等重み融合が単独より有意に良い(近傍デコイ 99 件中 top-1: GL 47.5%、FP 41.5%、融合 59.0%)。他装置の公開ライブラリ分子では ICE 追加が効き、FP+GL の優位は弱い(CE 欠損などの交絡あり)。公開パイプラインのパネルでの順方向モデル評価は MassSpecGym との重複(250 分子中 236 が収載、204 が train fold)により過大評価の恐れがあり、未見分子での再評価が必要。
  3. 公開最高系譜(V18 = 0.464 構成)への設定変更(ICE 追加・GL 重み増・窓拡大)を支持する比較は無い。 公開系譜の 0.373→0.455 の積み上げは Public LB 約 130 分子での選択で、CV の裏付けが無い(ディスカッション 748068、Codex 001 も同意)。
  4. 提出: E0(V18 忠実再現)のみ提出(submission 57567821、採点待ち)。根拠の無い設定変更の 2 本目は提出しない。
  5. 次の到達点(Codex 002 と合意した順序。「数日で 0.480」とは断定しない): (1) 評価と来歴の修正・凍結(E2b v2: 公式鍵での MSG 除外・候補同一性・正解判定、入力スペクトルの装置限定、電子補正の一貫適用)、(2) 学習コード付きの既存 FPNet と凍結 GL による基準系の構築(入賞要件は来歴の確保で満たし、自前変更は 1 fold で比較)、(3) 実際の shortlist 上で FP・GL・ICE・参照類似度・prior と欠損フラグを同じ候補行に揃え、小さな固定融合を基準に OOF 特徴を集めてから LambdaRank、(4) GLACIER の timsTOF 適応と対照学習は小規模試行で実現可能性(上流 ms-pred の学習コード、MAGMa 教師データ、GPU メモリ)を確認してから、(5) 生成経路は上記の評価系で「回収した正解」と「押し下げた既存正解」の両方を測る。最終 2 提出は「守り/攻め」でヘッジ。
  6. コンプライアンス: 公開系譜の第三者重み(fpnet_full1、v4b ランカー)は学習コード未公開で、運営の「全重みの学習コード提示」要件を満たさない可能性が高い。学習コードと分割監査が公開されている fold-safe FPNet のように来歴を確保できる重みは再学習不要で、再現できない重み・融合規則だけを置き換える。各 checkpoint と学習コード・設定・データ版の対応を manifest として保存する。
